# VRChat camera sync

This feature makes the dummy head microphone automatically follow the position of the VRChat User Camera. It reduces the mismatch where “the video is from the VRChat camera, but the audio comes from somewhere else.”

## Before you start

1. Open the VRChat Action Menu.
2. Open **Options → OSC**.
3. Enable OSC.
4. Show the VRChat User Camera.
5. Open **Main settings** in OVR-DummyHeadMic.

The connection is usually detected automatically. You can use other OSC-enabled apps at the same time in environments where OSCQuery is available.

Next, [calibrate the camera](calibration).
