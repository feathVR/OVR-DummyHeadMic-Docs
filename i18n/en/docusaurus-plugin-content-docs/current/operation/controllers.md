# Check your controller bindings

VR button names depend on your SteamVR controller bindings. This app's **How to use** page displays the binding names it can read in step 3 (grabbing the dummy head). Check that display first.

Typical controls are below. Both hands work the same way.

| Action | How |
| --- | --- |
| Grab and move it up close | Bring your hand to the head and squeeze the grip when a light-blue outline appears |
| Grab and move it from a distance | Point the beam at the head and squeeze the grip |
| Use the button row | Point the beam at the head to show a button row under it, then point at a button and pull the trigger |

The button row contains, from left to right:

| Button | What it does |
| --- | --- |
| Spatial audio (ASMR) | Turns spatial audio processing ON/OFF |
| Space settings | Chooses the room sound ([room preset](sound)) |
| Opacity | Cycles the display through 100→60→30→10% |
| Pin in place | Locks the dummy head so it cannot be grabbed by accident |
| Flip facing | Switches the [face direction](dummy-head) between Front and Back |

Other controllers may use different button names. If the app's display does not match your controller, check this app's controller binding in SteamVR. When the app cannot read a binding name, it may keep the default example text.

Turn the wrist menu on or off and select its hand under **Main settings**. Use the wrist icon to open it. The menu may be hidden while the SteamVR dashboard is open. See [common issues](../troubleshooting/common-issues) if it does not appear.
