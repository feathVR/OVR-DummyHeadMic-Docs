# Main settings reference

Open settings pages from the left navigation in the app. Choose an [audio route](../audio/routes) first, then adjust only the settings you need.

## Main settings

| Setting | What it changes |
| --- | --- |
| ASMR | Turns spatial audio on or off. White is on; red is off. |
| Dummy head type | Changes the listening profile: Standard, KU100, or KEMAR. Compare with headphones. |
| Space settings | Selects a room reverb preset. No reverb makes positioning easier to check. |
| Output volume | Sets processed audio level. Also check the OBS or DAW meter. |
| Dummy head opacity | Changes visibility in VR. Fully transparent can make it hard to find. |
| Face direction when placed | Front faces you; Back faces the same way you do. |
| Arm menu | Turns the wrist icon on/off and chooses which hand displays it. |
| Sync with VRChat camera | Starts or stops camera following. [Calibrate](../vrchat-camera/calibration) first. |

## Audio device settings

**Audio route** selects Normal or VST bridge. Normal uses microphone and output-device selections and has dropout protection. VST bridge uses the DAW's audio settings. Noise reduction is available in either route. See [Choose an audio route](../audio/routes).

## VRChat camera position and orientation

- **Camera forward offset**: moves the acoustic dummy head along the camera's facing direction by 0–100 cm. Adjust only when needed to align sound with video.
- **Camera height offset**: moves the acoustic position vertically by −20 to +20 cm.
- **Audio camera orientation**: choose Portrait when filming vertically. This is separate from VRChat's camera orientation switch.

If the position is far off, check Local Anchor, calibration, and the camera's front/rear switch before adjusting offsets.
