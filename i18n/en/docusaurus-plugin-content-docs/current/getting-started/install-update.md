# Install and update

Get OVR-DummyHeadMic from its distribution source. Installation depends on the edition you received.

## Manually distributed edition

1. Extract the supplied archive.
2. Keep the extracted folder together. Do not move bundled files such as `OVR-DummyHeadMic_Data` separately.
3. Start SteamVR, then `OVR-DummyHeadMic.exe`, and follow [Play your first sound](first-sound).

To update, get a new complete package from the distribution source. Extracting the full package into a new folder avoids mixing old and new bundled files. Settings are saved in the app, but check the audio route, devices, and VRChat sync after updating.

If you use the VST bridge, also [copy the newly bundled `VOrbit Bridge.vst3`](../audio/vst-bridge) to your DAW's scan directory again.

## Steam edition

Use Steam's installation and update flow for the Steam edition. Check the distribution source for release announcements and differences from the manually distributed edition.
