# Input and output devices

Under **Audio device settings**, select the input device that receives your voice and the output device that carries the processed audio.

## Input device

Select the microphone or audio interface you use for streaming or recording. “Default Device” uses the Windows default input.

## Output device

For monitoring only, select the output your headphones are connected to. For OBS, we recommend an output dedicated to this app, such as a virtual audio device.

Changing the output device restarts the audio engine. Wait briefly for the sound to return before checking it.

:::warning
Playing microphone audio directly through speakers can cause feedback. Use headphones or earphones while configuring the app.
:::
