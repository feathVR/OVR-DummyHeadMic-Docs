# VRChat 카메라 동기화

이 기능을 사용하면 더미 헤드 마이크가 VRChat User Camera의 위치를 자동으로 따라갑니다. "영상은 VRChat 카메라에서 나오지만 오디오는 다른 곳에서 들리는" 불일치를 줄여 줍니다.

## 시작하기 전에

1. VRChat Action Menu를 엽니다.
2. **Options → OSC**를 엽니다.
3. OSC를 활성화합니다.
4. VRChat User Camera를 표시합니다.
5. OVR-DummyHeadMic에서 **기본 설정**을 엽니다.

보통 연결은 자동으로 감지됩니다. OSCQuery를 사용할 수 있는 환경에서는 OSC를 사용하는 다른 앱도 동시에 사용할 수 있습니다.

다음으로 [카메라를 보정](calibration)하세요.

동기화를 시작한 뒤 표시되는 MOVE, WAIT, READY 같은 메시지에 대해서는 [상태 가이드](status)를 참조하세요.
