# 카메라 동기화 상태 이해하기

보정 중에는 화면과 VR에 표시되는 안내를 따르세요. 주요 상태는 다음과 같습니다.

| 표시 | 의미 및 조치 |
| --- | --- |
| VRChat에서 카메라를 여세요 | User Camera를 표시하고 VRChat에서 OSC가 활성화되어 있는지 확인하세요. |
| MOVE | 앱이 움직임을 감지했습니다. 카메라를 잡지 말고 이동이나 회전을 멈추세요. |
| WAIT | 입력하지 말고 자세가 안정될 때까지 기다리세요. |
| READY | 카메라를 잡고 [보정 단계](calibration)를 계속할 수 있습니다. |
| 점을 따라 좌우로 이동하세요 | 카메라의 높이와 방향을 일정하게 유지하고 직선으로 천천히 움직이세요. |
| 녹색 원 | 확인이 완료될 때까지 같은 손으로 카메라를 중앙에 고정하세요. |
| 추적 중 | 카메라 추적이 활성화되어 있습니다. |
| 일시 정지: 범위 밖 | 아바타에서 약 2.5 m 이내로 돌아오면 재개됩니다. |
| 일시 정지: 카메라를 한 번 움직이세요 | VRChat이 새로운 자세를 보내도록 카메라를 조금 움직이세요. |
| 위치 유실: 보정 다시 시작 | 처음부터 보정 안내를 다시 따르세요. |

MOVE 또는 WAIT가 오랫동안 유지되면 카메라를 잡은 상태에서 스틱으로 이동하거나 회전하고 있지 않은지 확인하세요. OSCQuery 대체 포트 메시지에 대해서는 [일반적인 문제](../troubleshooting/common-issues)를 참조하세요.
