# 해결되지 않은 문제 신고하기

[일반적인 문제](common-issues)로 해결되지 않으면 [Discord 커뮤니티](https://discord.gg/MJmu7Shger)에 문의하세요. VOrbit ASMR과 동일한 Discord 커뮤니티입니다. 가이드의 오타나 끊어진 링크는 [이 가이드의 GitHub Issues](https://github.com/feathVR/OVR-DummyHeadMic-Docs/issues)에 신고하세요.

가능한 항목을 포함하세요.

- 앱 에디션 및 버전
- Windows 버전, HMD 및 컨트롤러 유형
- 오디오 경로(일반 또는 VST 브리지), 일반 경로의 경우 입력 및 출력 장치
- VRChat 카메라 동기화 사용 여부, 앵커 유형 및 표시된 상태
- 재현 단계, 예상 결과 및 실제 결과
- 필요하다면 개인 정보를 가린 스크린샷

지원 담당자가 로그를 요청하면 Unity의 `Player.log`를 확인하세요. 일반적인 Windows 설치에서는 `%USERPROFILE%\AppData\LocalLow\feath\OVR-DummyHeadMic\Player.log`에 있습니다. 장치 이름이나 기타 로컬 환경 정보가 포함될 수 있으므로 공개 Issue에 첨부하기 전에 내용을 확인하세요.

같은 폴더에는 앱이 자동으로 작성하는 `support-info.txt`도 있습니다. 앱 버전, 오디오 경로, 선택한 입력 및 출력 장치, 샘플 레이트, VST 브리지 및 VRChat 동기화 상태가 한 페이지에 요약되어 있어 함께 보내면 원인을 빠르게 좁히는 데 도움이 됩니다. 이 파일은 사용자의 PC에만 생성되며 자동으로 전송되지 않습니다. 장치 및 DAW 이름이 포함되어 있으므로 공유하기 전에 내용을 확인하세요.
