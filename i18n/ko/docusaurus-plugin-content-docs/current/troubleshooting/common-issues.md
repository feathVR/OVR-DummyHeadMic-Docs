# 일반적인 문제

## 앱을 시작해도 창이 나타나지 않음

OVR-DummyHeadMic은 창을 표시하지 않고 시작되어 Windows 시스템 트레이(화면 오른쪽 아래 알림 영역)에 자리 잡습니다.

- OVR-DummyHeadMic 트레이 아이콘을 클릭하여 설정 창을 여세요. 아이콘이 보이지 않으면 알림 영역의 "^"를 여세요.
- 아이콘을 마우스 오른쪽 버튼으로 클릭하여 **설정 열기** 또는 **OVR-DummyHeadMic 종료**를 선택하세요.
- 창의 닫기 버튼(×)은 앱을 종료하지 않고 트레이로 되돌립니다. 종료하려면 트레이 메뉴를 사용하세요.
- 트레이 대신 창이 보이는 상태로 시작하려면 `-showwindow` 실행 옵션을 추가하세요.

## 오디오가 나오지 않음

- **오디오 경로**가 일반인지 VST 브리지인지 확인하세요. DAW를 사용하지 않는다면 일반을 선택하세요.
- 입력 장치가 사용 중인 마이크인지 확인하세요.
- 출력 장치가 헤드폰이 연결된 곳과 일치하는지 확인하세요.
- Windows와 앱의 음소거 및 볼륨 설정을 확인하세요.
- 다른 앱이 오디오 장치를 단독으로 사용 중인지 확인하세요.
- 장치를 변경한 뒤 오디오 엔진이 다시 시작될 때까지 잠시 기다리세요.

## OBS에 오디오가 도달하지 않음

- 다음 단계는 일반 경로용입니다. VST 브리지의 경우 [DAW 경로](../audio/vst-bridge)를 확인하세요.
- OBS에 "오디오 입력 캡처"가 아닌 **오디오 출력 캡처**를 추가하세요.
- OVR-DummyHeadMic과 OBS에서 동일한 출력 장치를 선택하세요.
- OBS 소스와 오디오 믹서가 음소거되어 있지 않은지 확인하세요.

## 처리되지 않은 음성과 처리된 음성이 모두 들림

OBS에서 일반 마이크 입력을 음소거하세요. 스트리밍에는 OVR-DummyHeadMic의 출력을 캡처하는 오디오 출력 캡처만 사용하세요.

## 더미 헤드를 움직일 수 없음

- SteamVR이 두 컨트롤러를 모두 인식하는지 확인하세요.
- 왼쪽 X + 오른쪽 A 또는 양쪽 A 버튼을 동시에 길게 누르세요.
- VRChat 카메라 동기화가 활성화되어 있다면 동기화를 잠시 종료하여 수동 배치로 돌아가세요.
- 다른 컨트롤러나 사용자 지정 바인딩을 사용하는 경우 [앱 내 바인딩 이름](../operation/controllers)을 확인하세요.

## 끊김 또는 원치 않는 소음

- 일반 모드에서는 오디오 장치 설정 아래의 **드롭아웃 방지(링 버퍼)**를 사용해 보세요. 전환하면 오디오 엔진이 다시 시작됩니다.
- 일정한 배경 소음에는 소음 감소를 사용해 보세요. 음성의 특성이 달라진다면 끄세요.
- 장치 연결과 다른 앱이 장치를 단독으로 사용 중인지 확인하세요.

## VST 브리지가 연결되지 않음

- DAW에 `VOrbit Bridge`를 삽입하고 필요하면 플러그인을 다시 검색하세요.
- DAW 샘플 레이트를 44.1 또는 48 kHz로 설정하세요.
- 다른 앱이 브리지를 사용 중이라면 해당 앱의 브리지 모드를 먼저 종료하세요.
- 구체적인 메시지는 [VST 브리지 상태 가이드](../audio/vst-bridge)를 참조하세요.

## VRChat 카메라가 감지되지 않음

- VRChat Action Menu에서 OSC가 활성화되어 있는지 확인하세요.
- "시작"을 누르기 전에 User Camera를 표시하세요.
- VRChat이나 이 앱을 다시 시작했다면 "시작"을 다시 누르세요.
- 방화벽이나 보안 소프트웨어가 로컬 통신, mDNS 또는 OSC를 차단하고 있지 않은지 확인하세요.
- OSCQuery를 시작할 수 없다는 메시지가 표시되면 다른 OSC 수신 앱과 포트가 충돌하는지 확인하세요.

## 보정이 완료되지 않음

- 같은 손으로 카메라를 수평으로 유지하며 천천히 움직이세요.
- 좌우로 이동할 때는 방향과 높이를 일정하게 유지하고 각 방향으로 한 번씩 직선으로 움직이세요.
- 방향을 측정할 때는 위치를 고정하고 카메라 방향만 바꾸세요.
- 카메라를 잡은 상태에서 스틱으로 이동하거나 회전하지 마세요.

## 동기화 위치가 어긋남

- 보정 후 카메라의 셀카/바깥쪽 방향이 바뀌지 않았는지 확인하세요.
- 아바타를 변경하거나 다시 불러온 뒤에는 다시 보정하세요.
- 세로 촬영 시 "음향 카메라 방향"을 "세로"로 설정하세요.
- World Anchor나 Pin이 아닌 Local Anchor를 사용하세요.

문제가 계속되면 [신고 방법](report)을 참조하세요.
