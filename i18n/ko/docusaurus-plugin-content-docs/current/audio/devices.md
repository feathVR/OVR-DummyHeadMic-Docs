# 입력 및 출력 장치

**오디오 장치 설정**의 일반 오디오 경로에서 음성을 받는 입력 장치와 처리된 오디오를 내보낼 출력 장치를 선택하세요. DAW를 사용하는 경우 [VST 브리지](vst-bridge) 안내를 따르세요.

## 입력 장치

스트리밍이나 녹음에 사용할 마이크 또는 오디오 인터페이스를 선택하세요. "기본 장치"는 Windows의 기본 입력을 사용합니다.

## 출력 장치

모니터링만 할 때는 헤드폰이 연결된 출력을 선택하세요. OBS에는 가상 오디오 장치처럼 이 앱 전용 출력을 사용하는 것을 권장합니다.

출력 장치를 변경하면 오디오 엔진이 다시 시작됩니다. 소리가 돌아올 때까지 잠시 기다린 후 확인하세요.

저장된 장치가 다음 실행 시 없으면 앱이 기본 장치로 되돌아갑니다. 장치의 연결을 해제하거나 이름을 바꾼 뒤에는 선택 항목을 확인하세요.

:::warning
마이크 오디오를 스피커로 직접 재생하면 피드백이 발생할 수 있습니다. 앱을 설정할 때는 헤드폰이나 이어폰을 사용하세요.
:::
