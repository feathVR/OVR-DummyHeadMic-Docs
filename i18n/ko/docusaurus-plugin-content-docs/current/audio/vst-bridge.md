# DAW에서 VST 브리지 사용하기

VST 브리지는 DAW의 오디오를 `VOrbit Bridge.vst3`를 통해 이 앱으로 보내고 처리된 오디오를 DAW로 돌려보냅니다. DAW를 사용하지 않는다면 [일반 경로](routes)를 선택하세요.

## 최초 설정

1. 이 앱의 **오디오 장치 설정**에서 **VST 브리지 폴더 열기**를 클릭합니다.
2. `VOrbit Bridge.vst3` 폴더 전체를 VST3 검색 디렉터리에 복사합니다. 사용자별 위치는 `%LOCALAPPDATA%\Programs\Common\VST3`, 모든 사용자용 위치는 `%COMMONPROGRAMFILES%\VST3`입니다. DAW에 다른 검색 위치가 설정되어 있다면 해당 위치를 사용하세요.
3. DAW에서 플러그인을 다시 검색하고 처리할 오디오 트랙에 **VOrbit Bridge**를 삽입합니다. 마이크 트랙에 삽입한 경우 DAW에서 입력 모니터링을 활성화하세요.
4. DAW 샘플 레이트를 **44.1 kHz 또는 48 kHz**로 설정합니다.
5. 이 앱의 **오디오 경로**를 **VST 브리지**로 전환합니다. 상태가 **공간 음향 처리 중**으로 표시되고 오디오가 DAW에 도달하는지 확인합니다.

:::note
플러그인 이름이 "VOrbit Bridge"인 이유는 번들 플러그인의 이름이기 때문입니다. OVR-DummyHeadMic용으로 이름을 바꿀 필요는 없습니다.
:::

## 상태 및 제어

| 상태 | 의미 및 다음 단계 |
| --- | --- |
| DAW에서 VOrbit Bridge를 기다리는 중 | DAW에 플러그인을 삽입하고 오디오 처리를 시작하세요. 이미 연결되어 있었다면 **VST 브리지 다시 연결**을 사용해 보세요. |
| 공간 음향 처리 중 | 연결되었습니다. DAW의 라우팅과 트랙 레벨을 확인하세요. |
| 지원되지 않는 샘플 레이트: 바이패스 | DAW 샘플 레이트를 44.1 또는 48 kHz로 변경하세요. |
| 오프라인 렌더링: 바이패스 | 오프라인 렌더링 중에는 공간 음향 처리가 우회됩니다. 실시간 재생으로 확인하세요. |
| 다른 앱이 VST 브리지를 사용 중 | VOrbit ASMR 또는 같은 브리지를 사용하는 다른 앱에서 브리지 모드를 종료한 뒤 다시 연결하세요. |

**VST 브리지 연결 해제**는 현재 DAW 연결을 해제하고 플러그인을 바이패스 상태로 둡니다. **VST 브리지 다시 연결**은 대기 중인 연결을 다시 시도합니다.

앱을 업데이트한 뒤에는 새로 포함된 플러그인을 DAW 검색 디렉터리에 다시 복사하고 DAW에서 다시 검색하세요.

## OBS로 스트리밍하기

VST 브리지를 사용하면 공간 음향 처리된 오디오가 DAW로 돌아갑니다. 이를 스트리밍하려면 DAW 출력을 가상 오디오 장치로 보내고 OBS의 **오디오 출력 캡처**로 캡처하는 방식처럼, **DAW에서 처리된 오디오를 OBS로 전달하는 별도 경로를 설정하세요**. 환경에 맞는 방법을 선택하세요.

헤드폰으로 들린다고 해서 OBS에도 도달하는 것은 아닙니다. OBS 오디오 미터를 확인하고 짧게 테스트 녹화를 하세요. 처리되지 않은 음성이 이중으로 캡처되지 않도록 OBS의 일반 마이크 입력은 음소거하세요.

## 다시 연결할 필요가 없는 경우

- **경로 전환**: 일반과 VST 브리지를 전환해도 DAW 연결은 유지됩니다. 일반을 선택한 동안에는 DAW의 플러그인이 오디오를 그대로 통과시키며, VST 브리지로 돌아가면 공간 음향 처리가 재개됩니다.
- **앱 시작**: 앱을 시작하면(또는 시작 후 VST 브리지를 처음 선택하면) DAW에서 대기 중인 플러그인에 자동으로 재연결을 요청합니다.

**VST 브리지 연결 해제**를 누른 뒤에는 연결이 자동으로 복구되지 않습니다. 다시 연결하려면 **VST 브리지 다시 연결**을 누르세요.

앱에서 추가되는 지연 시간과 DAW의 지연 시간 보정에 대해서는 [지연 시간](routes#latency)을 참조하세요.
