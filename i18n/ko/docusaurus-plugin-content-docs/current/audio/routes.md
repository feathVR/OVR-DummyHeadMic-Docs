# 오디오 경로 선택하기

**오디오 장치 설정 → 오디오 경로**에서 **일반** 또는 **VST 브리지**를 선택하세요. 선택한 항목은 다음 실행 시 복원됩니다.

| 경로 | 오디오 흐름 | 적합한 용도 |
| --- | --- | --- |
| 일반 | 마이크 → OVR-DummyHeadMic → Windows 출력 장치 | 헤드폰 확인 및 [OBS 캡처](obs) |
| VST 브리지 | DAW 트랙 → VOrbit Bridge.vst3 → OVR-DummyHeadMic → DAW | DAW에서 모니터링 및 녹음 |

먼저 일반 경로에서 소리를 확인하세요. VST 브리지 모드에서는 입력/출력 장치와 링 버퍼 제어 항목이 숨겨지므로 오디오 장치는 DAW에서 설정하세요. 일반 경로용 OBS 오디오 출력 캡처 안내는 VST 브리지 모드에 그대로 적용되지 않습니다.

## 두 경로에서 공통으로 사용하는 설정

- **일정한 배경 소음 줄이기**: PC 팬이나 에어컨 같은 소리를 줄입니다. 기본값은 꺼짐입니다. 속삭임이나 숨소리의 질감이 달라질 수 있으며 앱 지연 시간이 약 10 ms 늘어납니다.
- **드롭아웃 방지(링 버퍼)**: 일반 모드에서 오디오가 끊길 때 사용해 보세요. 이 설정을 변경하면 오디오 엔진이 다시 시작됩니다. VST 브리지 모드에서는 숨겨집니다.

## 지연 시간 {#latency}

앱의 상태 표시에는 총 지연 시간과 세부 내역이 표시됩니다. 고정되는 부분은 다음과 같습니다.

| 부분 | 길이 | 적용 시점 |
| --- | --- | --- |
| 공간 음향 처리 | 5 ms | 항상 |
| 일정한 배경 소음 줄이기 | 10 ms | 켰을 때 |
| 리버브 | 설정에 따라 다름 | 사용할 때 |

- **일반 경로**: 위 항목에 더해 마이크와 출력 장치 자체의 I/O 지연 시간이 추가됩니다. 하드웨어에 따라 다르지만 합계 약 20 ms가 일반적이므로 전체 지연 시간은 대략 25 ms입니다(소음 감소를 켜면 약 35 ms). **드롭아웃 방지(링 버퍼)**를 켜면 더 늘어납니다.
- **VST 브리지**: 앱에서는 위 항목만 추가됩니다(소음 감소가 꺼져 있으면 5 ms). 오디오 장치 I/O는 DAW에서 설정되며 앱 표시에 포함되지 않습니다. 플러그인은 이 지연 시간을 DAW에 보고하므로 DAW의 지연 시간 보정을 통해 녹음과 렌더링의 타이밍이 유지됩니다. 지연은 실시간 모니터링 중에만 느껴집니다.
