# OBS에서 오디오 캡처하기

1. OBS에서 사용할 장면을 엽니다.
2. 소스 아래의 "+"를 선택하고 **오디오 출력 캡처** 소스를 추가합니다.
3. OVR-DummyHeadMic에 설정한 출력 장치를 선택합니다.
4. 마이크에 대고 말하여 OBS 오디오 미터가 움직이는지 확인합니다.
5. OBS에서 일반 마이크 입력을 음소거합니다.

<ObsFlowFigure />

:::danger 처리되지 않은 음성을 이중으로 캡처하지 마세요
처리된 OVR-DummyHeadMic 오디오와 OBS 마이크 입력을 모두 활성화하면 처리되지 않은 음성과 공간 음향이 함께 송출됩니다. 원칙적으로 OBS의 일반 마이크 입력은 음소거하세요.
:::

## 게임 오디오나 알림음도 함께 캡처되는 경우

오디오 출력 캡처는 선택한 장치로 전송되는 모든 소리를 캡처합니다. 다른 앱의 소리를 포함하지 않으려면 전용 가상 오디오 장치를 사용하세요.
