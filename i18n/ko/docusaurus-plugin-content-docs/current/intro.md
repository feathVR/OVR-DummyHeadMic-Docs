# OVR-DummyHeadMic 사용자 가이드

OVR-DummyHeadMic은 VR에 가상 더미 헤드 마이크를 배치하고 사용자의 음성을 실시간으로 바이노럴 오디오로 변환하는 Windows SteamVR 오버레이 애플리케이션입니다. VR 스트리밍과 녹화에 마이크를 기준으로 한 화자의 위치를 반영할 수 있습니다.

이 가이드에서는 오디오 장치 설정, OBS로 오디오 보내기, 더미 헤드 배치, 공간 음향 조정, VRChat 카메라와 동기화 및 문제 해결 방법을 설명합니다.
