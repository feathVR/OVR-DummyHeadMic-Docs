# 컨트롤러 바인딩 확인하기

VR 버튼 이름은 SteamVR 컨트롤러 바인딩에 따라 다릅니다. 이 앱의 **사용 방법** 페이지에는 3단계(더미 헤드 배치)와 5단계(공간 음향 전환)에 대해 앱이 읽을 수 있는 바인딩 이름이 표시됩니다. 먼저 이 표시를 확인하세요.

일반적인 Quest 스타일 컨트롤러 바인딩은 다음과 같습니다.

| 동작 | 일반적인 버튼 |
| --- | --- |
| 오른손을 따라 더미 헤드 배치 | 왼쪽 X + 오른쪽 A 또는 양쪽 A 버튼을 길게 누르기 |
| 공간 음향 전환 | 왼쪽 Y + 오른쪽 B 또는 양쪽 B 버튼 누르기 |

다른 컨트롤러에서는 버튼 이름이 다를 수 있습니다. 앱의 표시가 컨트롤러와 맞지 않으면 SteamVR에서 이 앱의 컨트롤러 바인딩을 확인하세요. 앱이 바인딩 이름을 읽지 못하면 기본 예시 문구가 계속 표시될 수 있습니다.

**기본 설정**에서 손목 메뉴를 켜거나 끄고 표시할 손을 선택하세요. 손목 아이콘을 사용하여 메뉴를 엽니다. SteamVR 대시보드가 열려 있는 동안에는 메뉴가 숨겨질 수 있습니다. 메뉴가 나타나지 않으면 [일반적인 문제](../troubleshooting/common-issues)를 참조하세요.
