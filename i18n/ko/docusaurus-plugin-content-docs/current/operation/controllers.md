# 컨트롤러 바인딩 확인하기

VR 버튼 이름은 SteamVR 컨트롤러 바인딩에 따라 다릅니다. 이 앱의 **How to use** 페이지에는 3단계(더미 헤드 잡기)에 앱이 읽을 수 있는 바인딩 이름이 표시됩니다. 먼저 이 표시를 확인하세요.

일반적인 조작은 다음과 같습니다. 왼손과 오른손 모두 같은 방법으로 사용할 수 있습니다.

| 동작 | 방법 |
| --- | --- |
| 가까이에서 잡아 옮기기 | 손을 머리에 가까이 대고 하늘색 윤곽선이 나타나면 그립을 쥐기 |
| 멀리서 잡아 옮기기 | 빔으로 머리를 가리키고 그립을 쥐기 |
| 버튼 줄 사용하기 | 빔으로 머리를 가리키면 머리 아래에 버튼 줄이 나타나므로, 버튼을 가리키고 트리거를 당기기 |

버튼 줄에는 왼쪽부터 다음 버튼이 있습니다.

| 버튼 | 동작 |
| --- | --- |
| 공간 음향(ASMR) | 공간 음향 처리 켜기/끄기 |
| 공간 설정 | 방의 울림([공간 프리셋](sound)) 선택 |
| 투명도 | 표시 농도를 100→60→30→10% 순서로 전환 |
| 위치 고정 | 더미 헤드를 잡을 수 없게 하여 실수로 움직이는 것을 방지 |
| 방향 반전 | [얼굴 방향](dummy-head)을 앞⇔뒤로 전환 |

다른 컨트롤러에서는 버튼 이름이 다를 수 있습니다. 앱의 표시가 컨트롤러와 맞지 않으면 SteamVR에서 이 앱의 컨트롤러 바인딩을 확인하세요. 앱이 바인딩 이름을 읽지 못하면 기본 예시 문구가 계속 표시될 수 있습니다.

**Main settings**에서 손목 메뉴를 켜거나 끄고 표시할 손을 선택하세요. 손목 아이콘을 사용하여 메뉴를 엽니다. SteamVR 대시보드가 열려 있는 동안에는 메뉴가 숨겨질 수 있습니다. 메뉴가 나타나지 않으면 [일반적인 문제](../troubleshooting/common-issues)를 참조하세요.
