# 더미 헤드 배치하기

## 수동으로 이동하기

일반적인 바인딩에서는 왼쪽 X + 오른쪽 A 또는 양쪽 A 버튼을 누르는 동안 더미 헤드가 오른손을 따라갑니다. 원하는 위치로 옮긴 다음 버튼을 놓으세요. 사용 중인 컨트롤러의 [앱 내 바인딩 이름](controllers)을 확인하세요.

## 얼굴 방향

**기본 설정**의 "오른손에 부착했을 때의 얼굴 방향"에서 변경합니다.

- **앞**: 더미 헤드가 사용자를 바라봅니다.
- **뒤**: 더미 헤드가 사용자와 같은 방향을 바라봅니다.

"더미 헤드 불투명도"에서 표시 강도를 조절하세요. 완전히 투명하면 위치를 찾기 어려울 수 있으므로 배치하는 동안에는 약간 보이도록 두는 것을 권장합니다.
