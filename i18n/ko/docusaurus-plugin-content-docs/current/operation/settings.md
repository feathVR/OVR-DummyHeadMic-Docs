# 기본 설정 참고 자료

앱의 왼쪽 탐색 메뉴에서 설정 페이지를 여세요. 먼저 [오디오 경로](../audio/routes)를 선택한 다음 필요한 설정만 조정하세요.

## 기본 설정

| 설정 | 변경되는 항목 |
| --- | --- |
| ASMR | 공간 음향을 켜거나 끕니다. 흰색은 켜짐, 빨간색은 꺼짐입니다. |
| 더미 헤드 유형 | 청취 프로필을 표준, KU100 또는 KEMAR로 변경합니다. 헤드폰으로 비교하세요. |
| 공간 설정 | 실내 리버브 프리셋을 선택합니다. 리버브 없음은 위치를 더 쉽게 확인할 수 있습니다. |
| 출력 볼륨 | 처리된 오디오 레벨을 설정합니다. OBS 또는 DAW 미터도 확인하세요. |
| 더미 헤드 불투명도 | VR에서의 가시성을 변경합니다. 완전히 투명하면 찾기 어려울 수 있습니다. |
| 배치 시 얼굴 방향 | 앞은 사용자를 바라보고, 뒤는 사용자와 같은 방향을 바라봅니다. |
| 팔 메뉴 | 손목 아이콘을 켜거나 끄고 어느 손에 표시할지 선택합니다. |
| VRChat 카메라와 동기화 | 카메라 추적을 시작하거나 중지합니다. 먼저 [보정](../vrchat-camera/calibration)하세요. |
| SteamVR과 함께 자동 실행 | 켜면 다음부터 SteamVR과 함께 앱이 시작됩니다. SteamVR의 **시작/종료 → 시작 오버레이 앱 선택**과 동일한 설정이므로 어느 곳에서든 같은 상태가 표시됩니다. |

## 사용 방법

표준 및 VRChat 작업 흐름의 단계를 보여 줍니다. 각 단계 아래의 버튼은 튜토리얼 영상과 이 설명서에서 해당하는 페이지(표준 사용은 [처음으로 소리 재생하기](../getting-started/first-sound), VRChat은 [VRChat 카메라 동기화](../vrchat-camera/overview))를 엽니다. 앱이 영어로 설정되어 있으면 영어 설명서가 열립니다.

## 언어

설정 창의 **Language / 언어**에서 표시 언어를 선택합니다. 日本語, English, 简体中文, 繁體中文, 한국어, Русский, Español, Português (Brasil)의 8개 언어를 지원합니다. 재시작 없이 화면 전체가 바로 바뀌며, 사용 방법 아래의 설명서 버튼은 선택한 언어의 설명서를 엽니다. 처음 실행할 때는 Windows 표시 언어가 이 8개 언어 중 하나이고 해당 글꼴이 PC에 있으면 그 언어로, 그렇지 않으면 영어로 시작합니다. 사이드 메뉴의 페이지 이름(Main settings 등)은 모든 언어에서 영어로 유지됩니다.

## 오디오 장치 설정

**오디오 경로**에서 일반 또는 VST 브리지를 선택합니다. 일반은 마이크 및 출력 장치 선택과 드롭아웃 방지 기능을 사용합니다. VST 브리지는 DAW의 오디오 설정을 사용합니다. 어느 경로에서든 소음 감소를 사용할 수 있습니다. [오디오 경로 선택하기](../audio/routes)를 참조하세요.

## VRChat 카메라 위치 및 방향

- **카메라 전방 오프셋**: 음향 더미 헤드를 카메라가 향하는 방향으로 0–100 cm 이동합니다. 소리와 영상의 위치를 맞추기 위해 필요한 경우에만 조정하세요.
- **카메라 높이 오프셋**: 음향 위치를 수직으로 −20~+20 cm 이동합니다.
- **오디오 카메라 방향**: 세로로 촬영할 때 세로를 선택합니다. 이 설정은 VRChat의 카메라 방향 전환과 별개입니다.

위치가 크게 어긋나면 오프셋을 조정하기 전에 로컬 앵커, 보정 및 카메라 전면/후면 전환을 확인하세요.
