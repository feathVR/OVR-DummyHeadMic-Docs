# 처음으로 소리 재생하기

처음 확인할 때는 VRChat 카메라 동기화를 사용하지 말고 더미 헤드를 수동으로 배치하여 소리를 확인하세요.

1. SteamVR을 시작합니다.
2. OVR-DummyHeadMic을 시작합니다. 앱은 창을 표시하지 않고 시작되어 Windows 시스템 트레이(화면 오른쪽 아래 알림 영역)에 자리 잡습니다. 트레이 아이콘을 클릭하여 설정 창을 엽니다.
3. **오디오 장치 설정**에서 일반 오디오 경로를 선택하고 [입력 및 출력 장치](../audio/devices)를 선택합니다.
4. 헤드폰을 착용하고 마이크에 대고 말하여 오디오가 들리는지 확인합니다.
5. [컨트롤러 바인딩](../operation/controllers)을 확인합니다. 일반적인 바인딩은 왼쪽 X + 오른쪽 A 또는 양쪽 A 버튼입니다. 이 버튼들을 누른 채 오른손으로 더미 헤드를 움직입니다.
6. 더미 헤드의 양옆으로 이동하여 음성이 들리는 위치가 달라지는지 확인합니다.
7. 스트리밍이나 녹화를 한다면 [OBS 오디오 캡처](../audio/obs)를 설정합니다.

![OVR-DummyHeadMic 기본 설정 및 조작](/img/screenshots/en/basic-guide.png)

_입출력, OBS 캡처, 위치 이동 및 공간 음향 전환에 대한 개요입니다._

:::tip 소리의 위치를 구분하기 어려운 경우
더미 헤드를 앞에 놓은 다음 가까운 거리에서 좌우로 크게 움직여 보세요. 처음 확인할 때는 직접음의 위치를 더 쉽게 판단할 수 있도록 실내 리버브를 "리버브 없음"으로 설정하세요.
:::
