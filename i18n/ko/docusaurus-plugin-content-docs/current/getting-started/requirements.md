# 요구 사항

사용하기 전에 다음 항목을 준비하세요.

- Windows 10 또는 Windows 11 PC
- Steam 및 SteamVR
- SteamVR에서 인식되는 HMD와 좌우 컨트롤러
- 마이크
- 헤드폰 또는 이어폰
- 스트리밍이나 녹화를 할 경우 OBS Studio 또는 기타 캡처 소프트웨어
- VRChat 카메라 동기화를 사용할 경우 PC 버전 VRChat

:::warning 헤드폰을 사용하세요
바이노럴 오디오의 위치감을 확인하려면 헤드폰이나 이어폰이 필요합니다. 마이크 오디오를 스피커로 재생하면 피드백이 발생할 수도 있습니다.
:::

## 오디오 출력 선택하기

스트리밍 시에는 이 앱 전용 가상 오디오 장치나 사용하지 않는 출력 장치를 사용하면 오디오를 관리하기 쉽습니다. 평소 사용하는 스피커와 동일한 출력을 사용하면 게임 오디오와 알림음도 OBS에 캡처될 수 있습니다.
