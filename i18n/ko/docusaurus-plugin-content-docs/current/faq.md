# 자주 묻는 질문

## VRChat 이외에서도 사용할 수 있나요?

기본적인 수동 배치와 공간 음향 처리는 VRChat 전용 기능이 아닙니다. SteamVR과 해당 컨트롤러가 지원되는 모든 VR 환경에서 스트리밍 및 녹음용 음향 처리에 사용할 수 있습니다. 카메라 동기화는 VRChat 전용 기능입니다.

## 헤드폰이 필요한가요?

음원의 위치를 정확히 확인하고 마이크 피드백을 방지하려면 헤드폰이나 이어폰을 사용하는 것이 좋습니다.

## OBS에서 마이크 입력과 오디오 출력 중 무엇을 추가해야 하나요?

OBS의 **오디오 출력 캡처**를 사용하여 OVR-DummyHeadMic에 설정한 출력을 캡처하세요. 처리되지 않은 음성이 이중으로 캡처되지 않도록 일반 마이크 입력은 음소거하세요.

## VRChat 카메라 동기화를 매번 보정해야 하나요?

월드를 변경한 뒤에는 앱이 자동으로 다시 연결됩니다. 아바타를 변경하거나 다시 불러온 경우, 또는 카메라의 전면/후면 방향을 바꾼 경우에는 다시 보정하세요.

## 여러 OSC 앱을 동시에 사용할 수 있나요?

일반적으로 앱은 자동 감지에 OSCQuery를 사용하므로 다른 앱도 동시에 사용할 수 있습니다. OSCQuery를 시작하지 못해 앱이 대체 포트로 전환되면 동일한 수신 포트를 사용하는 앱과 충돌할 수 있습니다.

## 종료해도 설정이 저장되나요?

주요 설정은 앱에 저장되며 다음 실행 시 복원됩니다. 강제 종료나 SteamVR에서 시작된 종료에도 설정이 반영되도록, 중요한 설정을 변경한 뒤에는 앱을 닫기 전에 잠시 기다리세요.
