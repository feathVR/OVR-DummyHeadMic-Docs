# Сообщение о нерешённой проблеме

Если раздел [Распространённые неполадки](common-issues) не помог, обратитесь за помощью в [сообщество Discord](https://discord.gg/MJmu7Shger). Это то же сообщество Discord, что и у VOrbit ASMR. Об опечатках и неработающих ссылках в руководстве сообщайте через [GitHub Issues этого руководства](https://github.com/feathVR/OVR-DummyHeadMic-Docs/issues).

Укажите всё, что можете:

- Редакцию и версию приложения
- Версию Windows, модель VR-гарнитуры и тип контроллеров
- Аудиомаршрут (обычный или VST-мост); для обычного маршрута — устройства ввода и вывода
- Используется ли синхронизация с камерой VRChat, тип Anchor и отображаемое состояние
- Шаги для воспроизведения, ожидаемый и фактический результат
- Если полезно — снимок экрана со скрытыми личными данными

Если служба поддержки запросит журнал, найдите файл Unity `Player.log`. При типичной установке Windows он находится по пути `%USERPROFILE%\AppData\LocalLow\feath\OVR-DummyHeadMic\Player.log`. Он может содержать названия устройств и другие сведения о локальной среде, поэтому проверьте его перед прикреплением к общедоступной задаче Issue.

В той же папке находится файл `support-info.txt`, который приложение создаёт автоматически. На одной странице в нём собраны версия приложения, аудиомаршрут, выбранные устройства ввода и вывода, частоты дискретизации и состояние VST-моста и синхронизации с VRChat, поэтому его наличие помогает быстро сузить круг возможных причин. Файл создаётся только на вашем ПК и никогда не отправляется автоматически. Он содержит названия устройств и DAW, поэтому проверьте его перед отправкой.
