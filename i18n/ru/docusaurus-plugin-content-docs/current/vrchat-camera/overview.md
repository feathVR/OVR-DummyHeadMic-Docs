# Синхронизация с камерой VRChat

Эта функция заставляет макет головы с микрофонами автоматически следовать за положением User Camera в VRChat. Она уменьшает расхождение, при котором «изображение поступает с камеры VRChat, а звук — из другого места».

## Перед началом

1. Откройте меню действий VRChat.
2. Откройте **Options → OSC**.
3. Включите OSC.
4. Отобразите User Camera в VRChat.
5. Откройте **Основные настройки** в OVR-DummyHeadMic.

Обычно подключение обнаруживается автоматически. В средах, где доступен OSCQuery, можно одновременно использовать другие приложения с поддержкой OSC.

Затем [откалибруйте камеру](calibration).

Описание сообщений MOVE, WAIT и READY после запуска синхронизации см. в [руководстве по состояниям](status).
