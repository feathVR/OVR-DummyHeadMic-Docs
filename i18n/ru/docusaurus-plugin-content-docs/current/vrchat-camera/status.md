# Состояния синхронизации с камерой

Во время калибровки следуйте подсказкам на экране и в VR. Основные состояния:

| Отображаемый текст | Значение и действие |
| --- | --- |
| Откройте камеру в VRChat | Отобразите User Camera и убедитесь, что OSC включён в VRChat. |
| MOVE | Приложение обнаружило движение. Не берите камеру; перестаньте перемещаться или поворачиваться. |
| WAIT | Не выполняйте никаких действий и дождитесь стабилизации позы. |
| READY | Теперь можно взять камеру и продолжить [калибровку](calibration). |
| Следуйте за точкой влево и вправо | Сохраняйте высоту и ориентацию камеры; медленно перемещайте её по прямой. |
| Зелёный круг | Неподвижно удерживайте камеру в центре той же рукой до завершения подтверждения. |
| Следование | Следование за камерой активно. |
| Приостановлено: вне радиуса | Вернитесь на расстояние около 2,5 м от аватара, чтобы возобновить работу. |
| Приостановлено: переместите камеру один раз | Слегка переместите камеру, чтобы VRChat отправил свежие данные о положении. |
| Позиция потеряна: перезапуск калибровки | Снова выполните подсказки калибровки с самого начала. |

Если MOVE или WAIT отображается долгое время, убедитесь, что вы не перемещаетесь и не поворачиваетесь стиком, пока держите камеру. При сообщении о резервном порте OSCQuery см. [Распространённые неполадки](../troubleshooting/common-issues).
