# Часто задаваемые вопросы

## Можно ли использовать приложение за пределами VRChat?

Основные функции ручного размещения и пространственной обработки звука не привязаны к VRChat. Их можно использовать для обработки звука трансляций и записей в любой VR-среде, которую поддерживают SteamVR и её контроллеры. Синхронизация с камерой предназначена только для VRChat.

## Обязательно ли использовать наушники?

Чтобы точно оценить позиционирование и избежать акустической обратной связи, настоятельно рекомендуется использовать наушники.

## Что добавить в OBS: микрофонный вход или аудиовыход?

Захватывайте выход, настроенный в OVR-DummyHeadMic, с помощью источника OBS **Захват выходного аудиопотока**. Отключите обычный микрофонный вход, чтобы необработанный голос не записывался дважды.

## Нужно ли каждый раз калибровать синхронизацию с камерой VRChat?

После смены мира приложение переподключается автоматически. Выполните калибровку снова после смены или перезагрузки аватара, а также после переключения камеры между передней и задней ориентацией.

## Можно ли одновременно использовать несколько OSC-приложений?

Обычно приложение использует OSCQuery для автоматического обнаружения, поэтому другие приложения можно использовать одновременно. Если OSCQuery не удаётся запустить и приложение переключается на резервный порт, возможен конфликт с другим приложением, использующим тот же порт приёма.

## Сохраняются ли настройки при выходе?

Основные настройки сохраняются в приложении и восстанавливаются при следующем запуске. Чтобы учесть принудительное завершение работы или выход по инициативе SteamVR, после изменения важных настроек немного подождите, прежде чем закрывать приложение.
