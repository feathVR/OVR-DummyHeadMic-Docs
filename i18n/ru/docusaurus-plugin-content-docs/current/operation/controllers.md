# Проверка привязок контроллеров

Названия кнопок VR зависят от привязок контроллеров SteamVR. На странице **Как использовать** приложение показывает названия привязок, которые ему удалось определить, для шага 3 (захват макета головы). Сначала проверьте эти сведения.

Типичные действия перечислены ниже. Обе руки работают одинаково.

| Действие | Как выполнить |
| --- | --- |
| Взять и переместить вблизи | Поднесите руку к голове и, когда появится голубой контур, сожмите кнопку захвата (grip) |
| Взять и переместить издалека | Наведите луч на голову и сожмите кнопку захвата |
| Использовать ряд кнопок | Наведите луч на голову — под ней появится ряд кнопок; наведите луч на кнопку и нажмите на курок |

Ряд кнопок слева направо:

| Кнопка | Действие |
| --- | --- |
| Пространственный звук (ASMR) | Включает и выключает пространственную обработку звука |
| Настройки пространства | Выбор акустики помещения ([предустановка помещения](sound)) |
| Прозрачность | Переключает видимость по кругу: 100→60→30→10% |
| Закрепить | Не даёт взять макет головы, чтобы случайно его не сдвинуть |
| Развернуть | Переключает [направление лица](dummy-head) между «Вперёд» и «Назад» |

На других контроллерах названия кнопок могут отличаться. Если показанные в приложении сведения не соответствуют вашему контроллеру, проверьте привязку контроллера этого приложения в SteamVR. Если приложение не может определить название привязки, оно может продолжать показывать стандартный пример.

В разделе **Основные настройки** можно включить или выключить меню на запястье и выбрать руку, на которой оно отображается. Чтобы открыть меню, нажмите значок на запястье. Когда открыта панель SteamVR, меню может быть скрыто. Если оно не появляется, см. раздел [Распространённые неполадки](../troubleshooting/common-issues).
