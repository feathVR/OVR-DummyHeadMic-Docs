# Проверка привязок контроллеров

Названия кнопок VR зависят от привязок контроллеров SteamVR. На странице **Как использовать** приложение показывает названия привязок, которые ему удалось определить, для шага 3 (размещение макета головы) и шага 5 (включение и выключение пространственного звука). Сначала проверьте эти сведения.

Типичные привязки для контроллеров в стиле Quest:

| Действие | Типичные кнопки |
| --- | --- |
| Перемещение макета головы вслед за правой рукой | Удерживайте X на левом + A на правом контроллере либо кнопки A на обоих контроллерах |
| Включение и выключение пространственного звука | Нажмите Y на левом + B на правом контроллере либо кнопки B на обоих контроллерах |

На других контроллерах названия кнопок могут отличаться. Если показанные в приложении сведения не соответствуют вашему контроллеру, проверьте привязку контроллера этого приложения в SteamVR. Если приложение не может определить название привязки, оно может продолжать показывать стандартный пример.

В разделе **Основные настройки** можно включить или выключить меню на запястье и выбрать руку, на которой оно отображается. Чтобы открыть меню, нажмите значок на запястье. Когда открыта панель SteamVR, меню может быть скрыто. Если оно не появляется, см. раздел [Распространённые неполадки](../troubleshooting/common-issues).
