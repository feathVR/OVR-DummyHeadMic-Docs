# Справочник по основным настройкам

Страницы настроек открываются из левой панели навигации приложения. Сначала выберите [аудиомаршрут](../audio/routes), затем меняйте только необходимые параметры.

## Основные настройки

| Настройка | Что она изменяет |
| --- | --- |
| ASMR | Включает или выключает пространственный звук. Белый цвет означает, что он включён, красный — выключен. |
| Тип макета головы | Меняет профиль прослушивания: Standard, KU100 или KEMAR. Сравнивайте их в наушниках. |
| Настройки пространства | Выбирает предустановку реверберации помещения. Без реверберации позиционирование проверить проще. |
| Выходная громкость | Задаёт уровень обработанного звука. Также проверяйте индикатор OBS или DAW. |
| Непрозрачность макета головы | Меняет видимость в VR. Полностью прозрачный макет бывает трудно найти. |
| Направление лица при размещении | «Вперёд» — лицо направлено на вас; «Назад» — в ту же сторону, что и вы. |
| Меню на руке | Включает или выключает значок на запястье и выбирает руку, на которой он отображается. |
| Синхронизация с камерой VRChat | Запускает или останавливает следование за камерой. Сначала выполните [калибровку](../vrchat-camera/calibration). |
| Автоматически запускать со SteamVR | Если включено, со следующего раза приложение будет запускаться вместе со SteamVR. Это та же настройка, что и **Запуск / завершение работы → Выбрать оверлей-приложения для запуска** в SteamVR, поэтому в обоих местах отображается одно и то же состояние. |

## Как использовать

Здесь показаны шаги для стандартного сценария и работы с VRChat. Кнопки под каждым набором шагов открывают обучающее видео и соответствующую страницу этого руководства ([Первый звук](../getting-started/first-sound) для стандартного использования и [Синхронизация с камерой VRChat](../vrchat-camera/overview) для VRChat). Если в приложении выбран английский язык, открывается руководство на английском.

## Язык

Язык интерфейса выбирается параметром **Language / Язык** в окне настроек. Доступны 8 языков: 日本語, English, 简体中文, 繁體中文, 한국어, Русский, Español и Português (Brasil). Весь интерфейс переключается сразу, перезапуск не нужен, а кнопки руководства в разделе «Как пользоваться» открывают руководство на выбранном языке. При первом запуске приложение использует язык отображения Windows, если он входит в этот список и нужный шрифт есть на ПК, иначе — английский. Названия страниц в боковом меню (например, Main settings) остаются английскими на всех языках.

## Настройки аудиоустройств

Параметр **Аудиомаршрут** позволяет выбрать обычный маршрут или VST-мост. Обычный маршрут использует выбранные микрофон и устройство вывода и поддерживает защиту от прерываний. VST-мост использует аудионастройки DAW. Шумоподавление доступно для обоих маршрутов. См. [Выбор аудиомаршрута](../audio/routes).

## Положение и ориентация камеры VRChat

- **Смещение камеры вперёд**: перемещает акустический макет головы вдоль направления камеры на 0–100 см. Настраивайте только при необходимости совместить звук с изображением.
- **Смещение камеры по высоте**: перемещает акустическую позицию по вертикали на −20–+20 см.
- **Ориентация аудиокамеры**: при вертикальной съёмке выберите «Портретная». Этот параметр не связан с переключателем ориентации камеры VRChat.

Если позиция сильно смещена, прежде чем менять смещения, проверьте Local Anchor, калибровку и переключатель передней/задней ориентации камеры.
