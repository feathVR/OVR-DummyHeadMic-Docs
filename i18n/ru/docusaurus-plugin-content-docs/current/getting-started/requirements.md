# Системные требования

Перед использованием подготовьте следующее:

- ПК с Windows 10 или Windows 11
- Steam и SteamVR
- VR-гарнитуру и левый и правый контроллеры, распознаваемые SteamVR
- Микрофон
- Наушники
- OBS Studio или другое ПО для захвата, если вы планируете вести трансляцию или запись
- Версию VRChat для ПК, если вы планируете использовать синхронизацию с камерой VRChat

:::warning Используйте наушники
Наушники необходимы для проверки позиционирования бинаурального звука. Воспроизведение звука микрофона через колонки также может вызвать акустическую обратную связь.
:::

## Выбор аудиовыхода

Для трансляций управлять звуком проще, если выделить этому приложению виртуальное аудиоустройство или неиспользуемый выход. Если выбрать тот же выход, что и для обычных колонок, OBS может также захватывать звук игры и уведомлений.
