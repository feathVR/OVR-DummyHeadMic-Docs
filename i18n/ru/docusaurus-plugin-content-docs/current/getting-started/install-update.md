# Установка и обновление

Получите OVR-DummyHeadMic из источника распространения. Порядок установки зависит от полученной редакции.

## Редакция с ручным распространением

1. Распакуйте предоставленный архив.
2. Храните распакованную папку целиком. Не перемещайте отдельно входящие в комплект файлы и папки, например `OVR-DummyHeadMic_Data`.
3. Запустите SteamVR, затем `OVR-DummyHeadMic.exe` и следуйте инструкции [Первый звук](first-sound).

:::tip
Чтобы приложение каждый раз запускалось вместе со SteamVR, включите **Автоматически запускать со SteamVR** в разделе **Основные настройки** (см. [Справочник по основным настройкам](../operation/settings)). Если вы переместили папку, один раз запустите `OVR-DummyHeadMic.exe` из нового расположения.
:::

Для обновления получите новый полный пакет из источника распространения. Распаковка полного пакета в новую папку позволит избежать смешивания старых и новых файлов из комплекта. Настройки сохраняются в приложении, однако после обновления проверьте аудиомаршрут, устройства и синхронизацию с VRChat.

Если вы используете VST-мост, также ещё раз [скопируйте новую версию `VOrbit Bridge.vst3` из комплекта](../audio/vst-bridge) в каталог сканирования вашей DAW.

## Редакция Steam

Для редакции Steam используйте штатные средства установки и обновления Steam. Информацию о выпусках и отличиях от редакции с ручным распространением смотрите в источнике распространения.
