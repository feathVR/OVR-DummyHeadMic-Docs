# Устройства ввода и вывода

При обычном аудиомаршруте в разделе **Настройки аудиоустройств** выберите устройство ввода, на которое поступает ваш голос, и устройство вывода для обработанного звука. При работе с DAW следуйте инструкции по [VST-мосту](vst-bridge).

## Устройство ввода

Выберите микрофон или аудиоинтерфейс, который используется для трансляции или записи. Пункт «Устройство по умолчанию» использует устройство ввода Windows по умолчанию.

## Устройство вывода

Если звук нужен только для мониторинга, выберите выход, к которому подключены наушники. Для OBS рекомендуется выделить отдельный выход, например виртуальное аудиоустройство.

При смене устройства вывода аудиодвижок перезапускается. Прежде чем проверять звук, немного подождите, пока он восстановится.

Если при следующем запуске сохранённое устройство не найдено, приложение переключится на устройство по умолчанию. После отключения или переименования устройства проверьте выбранный вариант.

:::warning
Воспроизведение звука микрофона непосредственно через колонки может вызвать акустическую обратную связь. Во время настройки приложения используйте наушники.
:::
