# 選擇音訊路徑

在**音訊裝置設定 → 音訊路徑**中，選擇**一般**或 **VST bridge**。您的選擇會在下次啟動時還原。

| 路徑 | 音訊流程 | 適合用途 |
| --- | --- | --- |
| 一般 | 麥克風 → OVR-DummyHeadMic → Windows 輸出裝置 | 耳機確認與 [OBS 擷取](obs) |
| VST bridge | DAW 音軌 → VOrbit Bridge.vst3 → OVR-DummyHeadMic → DAW | 在 DAW 中監聽與錄音 |

請先使用「一般」確認聲音。在 VST bridge 模式中，輸入／輸出裝置與環形緩衝區控制項會隱藏；請改在 DAW 中設定音訊裝置。「一般」路徑的 OBS 音訊輸出擷取說明無法直接套用於 VST bridge 模式。

## 兩種路徑共用的設定

- **降低穩定的背景雜音**：降低電腦風扇和空調等聲音。預設為關閉。此功能可能改變耳語或呼吸聲的質感，並增加約 10 ms 的應用程式延遲。
- **音訊中斷保護（環形緩衝區）**：若「一般」模式發生音訊中斷，請嘗試此設定。變更此設定會重新啟動音訊引擎。在 VST bridge 模式中會隱藏。

## 延遲 {#latency}

應用程式的狀態顯示會顯示總延遲及其細分。固定部分如下：

| 部分 | 長度 | 使用時機 |
| --- | --- | --- |
| 空間化器 | 5 ms | 一律使用 |
| 降低穩定的背景雜音 | 10 ms | 開啟時 |
| 殘響 | 依設定而異 | 使用時 |

- **一般路徑**：除了上述部分之外，麥克風和輸出裝置還會加上各自的 I/O 延遲。此延遲視硬體而定，但總計通常約為 20 ms，因此整體延遲約為 25 ms（開啟雜音抑制時約為 35 ms）。開啟**音訊中斷保護（環形緩衝區）**會再增加延遲。
- **VST bridge**：應用程式只會加上上述部分（關閉雜音抑制時為 5 ms）。音訊裝置 I/O 由 DAW 設定，不包含在應用程式的顯示中。外掛程式會將此延遲回報給 DAW，因此錄音與算繪可透過 DAW 的延遲補償保持同步。您只會在即時監聽時察覺延遲。
