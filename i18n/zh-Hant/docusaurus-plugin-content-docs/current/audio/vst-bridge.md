# 搭配 DAW 使用 VST bridge

VST bridge 會將 DAW 的音訊透過 `VOrbit Bridge.vst3` 傳送至本應用程式，再將處理後的音訊傳回 DAW。若不使用 DAW，請選擇[一般路徑](routes)。

## 首次設定

1. 在本應用程式的**音訊裝置設定**中，按一下**開啟 VST bridge 資料夾**。
2. 將整個 `VOrbit Bridge.vst3` 資料夾複製到 VST3 掃描目錄。每位使用者的位置為 `%LOCALAPPDATA%\Programs\Common\VST3`；所有使用者的位置為 `%COMMONPROGRAMFILES%\VST3`。若您的 DAW 設定了不同的掃描位置，請使用該位置。
3. 在 DAW 中重新掃描外掛程式，並將 **VOrbit Bridge** 插入要處理的音軌。若將它插入麥克風音軌，請在 DAW 中啟用輸入監聽。
4. 將 DAW 取樣率設為 **44.1 kHz 或 48 kHz**。
5. 將本應用程式的**音訊路徑**切換為 **VST bridge**。確認狀態顯示為**正在進行空間化處理**，且音訊已傳至 DAW。

:::note
此外掛程式名為「VOrbit Bridge」，因為這是隨附外掛程式的名稱。您不需要為 OVR-DummyHeadMic 重新命名。
:::

## 狀態與控制項

| 狀態 | 意義與後續步驟 |
| --- | --- |
| 正在等待 DAW 中的 VOrbit Bridge | 在 DAW 中插入外掛程式並開始處理音訊。若先前已連線，請嘗試**重新連線 VST bridge**。 |
| 正在進行空間化處理 | 已連線。請確認 DAW 的路由與音軌音量。 |
| 不支援的取樣率：略過 | 將 DAW 取樣率變更為 44.1 或 48 kHz。 |
| 離線算繪：略過 | 離線算繪時會略過空間音訊處理。請使用即時播放確認。 |
| 另一個應用程式正在使用 VST bridge | 結束 VOrbit ASMR 或其他使用相同 bridge 的應用程式中的 bridge 模式，然後重新連線。 |

**中斷 VST bridge 連線**會釋放目前的 DAW 連線，讓外掛程式維持略過狀態。**重新連線 VST bridge**會重試等候中的連線。

更新應用程式後，請再次將新隨附的外掛程式複製到 DAW 掃描目錄，並在 DAW 中重新掃描。

## 直播到 OBS

使用 VST bridge 時，空間化音訊會傳回 DAW。若要直播，**請另外設定一條路徑，將 DAW 處理後的音訊傳入 OBS**，例如將 DAW 輸出傳送至虛擬音訊裝置，再以 OBS 的**音訊輸出擷取**進行擷取。請選擇適合您環境的方法。

在耳機中聽見音訊並不代表音訊已傳至 OBS。請確認 OBS 音量表並進行一段簡短的測試錄影。將 OBS 中的一般麥克風輸入設為靜音，以免重複擷取未處理的語音。

## 不需要重新連線的情況

- **切換路徑**：在「一般」與 VST bridge 之間切換時，DAW 連線會保持不變。選擇「一般」時，DAW 中的外掛程式會直接傳遞音訊；切回 VST bridge 後，會恢復空間化處理。
- **啟動應用程式**：應用程式啟動時（或啟動後第一次選擇 VST bridge 時），會自動要求 DAW 中等候的外掛程式重新連線。

按下**中斷 VST bridge 連線**後，連線不會自行恢復。請按下**重新連線 VST bridge**再次連線。

若要瞭解應用程式增加的延遲與 DAW 的延遲補償，請參閱[延遲](routes#latency)。
