# 輸入與輸出裝置

在**音訊裝置設定**的「一般」音訊路徑中，選擇接收您語音的輸入裝置，以及輸出處理後音訊的輸出裝置。若使用 DAW，請依照 [VST bridge](vst-bridge) 的說明操作。

## 輸入裝置

選擇您用於直播或錄音的麥克風或音訊介面。「預設裝置」會使用 Windows 的預設輸入裝置。

## 輸出裝置

若僅用於監聽，請選擇耳機所連接的輸出裝置。若搭配 OBS 使用，建議選擇專供本應用程式使用的輸出，例如虛擬音訊裝置。

變更輸出裝置會重新啟動音訊引擎。請稍候片刻，等聲音恢復後再進行確認。

若下次啟動時找不到已儲存的裝置，應用程式會改用「預設裝置」。拔除裝置或重新命名裝置後，請確認您的選擇。

:::warning
直接透過喇叭播放麥克風音訊可能會造成回授。設定應用程式時請使用耳罩式耳機或入耳式耳機。
:::
