# OVR-DummyHeadMic 使用指南

OVR-DummyHeadMic 是一款 Windows SteamVR 覆蓋應用程式，可在 VR 中放置虛擬假人頭麥克風，並即時將您的語音轉換為雙耳音訊。它能讓 VR 直播與錄影反映說話者相對於麥克風的位置。

本指南說明如何設定音訊裝置、將音訊傳送至 OBS、放置假人頭、調整空間音訊、與 VRChat 攝影機同步，以及排解問題。
