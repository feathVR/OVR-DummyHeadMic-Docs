# 常見問題

## 啟動應用程式後未出現視窗

OVR-DummyHeadMic 啟動時不會顯示視窗，而是常駐於 Windows 系統匣（畫面右下角的通知區域）。

- 按一下 OVR-DummyHeadMic 系統匣圖示以開啟設定視窗。若看不到圖示，請展開通知區域中的「^」。
- 在圖示上按一下滑鼠右鍵，即可選擇**開啟設定**或**結束 OVR-DummyHeadMic**。
- 視窗的關閉按鈕（×）不會結束應用程式，而是讓應用程式回到系統匣。若要結束，請使用系統匣選單。
- 若要在啟動時顯示視窗，而非進入系統匣，請新增 `-showwindow` 啟動選項。

## 沒有音訊

- 確認**音訊路徑**為「一般」或 VST bridge。若不使用 DAW，請選擇「一般」。
- 確認輸入裝置是您正在使用的麥克風。
- 確認輸出裝置與耳機連接的位置相符。
- 確認 Windows 與應用程式中的靜音和音量設定。
- 確認是否有其他應用程式以獨佔模式使用音訊裝置。
- 變更裝置後，請稍候片刻，讓音訊引擎重新啟動。

## 音訊未傳至 OBS

- 以下步驟適用於「一般」路徑。若使用 VST bridge，請確認 [DAW 路徑](../audio/vst-bridge)。
- 在 OBS 中新增**音訊輸出擷取**，而不是「音訊輸入擷取」。
- 在 OVR-DummyHeadMic 與 OBS 中選擇相同的輸出裝置。
- 確認 OBS 來源與音訊混音器未設為靜音。

## 同時聽得到未處理與已處理的語音

將 OBS 中的一般麥克風輸入設為靜音。直播時只使用擷取 OVR-DummyHeadMic 輸出的「音訊輸出擷取」。

## 無法移動假人頭

- 確認 SteamVR 可辨識兩個控制器。
- 同時按住左手 X + 右手 A，或同時按住兩個 A 按鈕。
- 若 VRChat 攝影機同步已啟用，請暫時結束同步以回到手動放置。
- 若使用其他控制器或自訂按鍵綁定，請確認[應用程式內按鍵綁定名稱](../operation/controllers)。

## 音訊中斷或不需要的雜音

- 在「一般」模式中，請嘗試音訊裝置設定下的**音訊中斷保護（環形緩衝區）**。切換此設定會重新啟動音訊引擎。
- 若有穩定的背景雜音，請嘗試雜音抑制。若它改變了語音特性，請將其關閉。
- 確認裝置連線，以及是否有其他應用程式以獨佔模式使用裝置。

## VST bridge 無法連線

- 將 `VOrbit Bridge` 插入 DAW，並視需要重新掃描外掛程式。
- 將 DAW 取樣率設為 44.1 或 48 kHz。
- 若其他應用程式正在使用 bridge，請先結束該應用程式的 bridge 模式。
- 如需瞭解特定訊息，請參閱 [VST bridge 狀態指南](../audio/vst-bridge)。

## 未偵測到 VRChat 攝影機

- 確認已在 VRChat Action Menu 中啟用 OSC。
- 按下「開始」前先顯示 User Camera。
- 若您已重新啟動 VRChat 或本應用程式，請再次按下「開始」。
- 確認防火牆或安全性軟體未封鎖本機通訊、mDNS 或 OSC。
- 若訊息指出 OSCQuery 無法啟動，請確認是否與其他 OSC 接收器應用程式發生連接埠衝突。

## 無法完成校正

- 保持攝影機水平，並以同一隻手緩慢移動。
- 左右移動時，請保持方向與高度不變，沿直線各方向移動一次。
- 測量方向時，請固定位置，只變更攝影機方向。
- 握住攝影機時，請勿使用搖桿移動或轉向。

## 同步位置有偏移

- 確認攝影機的自拍／朝外方向自校正後未曾變更。
- 變更或重新載入虛擬人偶後，請重新校正。
- 若要直向拍攝，請將「聲學攝影機方向」設為「直向」。
- 請使用 Local Anchor，而非 World Anchor 或 Pin。

若問題仍然存在，請參閱[回報方式](report)。
