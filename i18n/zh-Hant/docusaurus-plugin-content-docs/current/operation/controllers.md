# 確認控制器按鍵綁定

VR 按鈕名稱會依 SteamVR 控制器按鍵綁定而異。本應用程式的**How to use**頁面會在步驟 3（抓取假人頭）中顯示可讀取到的按鍵綁定名稱。請先確認該處顯示的內容。

常見操作如下。左右手的用法相同。

| 動作 | 方式 |
| --- | --- |
| 在近處抓住並移動 | 將手靠近頭部，出現淺藍色輪廓線後握住握把 |
| 從遠處抓住並移動 | 用光束指向頭部，然後握住握把 |
| 使用按鈕列 | 用光束指向頭部，頭部下方會出現按鈕列；指向按鈕並扣下扳機 |

按鈕列由左至右依序為：

| 按鈕 | 作用 |
| --- | --- |
| 空間音訊（ASMR） | 開啟或關閉空間音訊處理 |
| 空間設定 | 選擇房間的殘響（[空間預設](sound)） |
| 透明度 | 依 100→60→30→10% 的順序切換顯示濃度 |
| 固定位置 | 讓假人頭無法被抓取，避免不小心移動 |
| 反轉朝向 | 在正面與背面之間切換[朝向](dummy-head) |

其他控制器可能使用不同的按鈕名稱。若應用程式中的顯示與您的控制器不符，請在 SteamVR 中確認本應用程式的控制器按鍵綁定。當應用程式無法讀取按鍵綁定名稱時，可能會保留預設的範例文字。

請在**Main settings**中開啟或關閉手腕選單，並選擇要顯示在哪一隻手上。使用手腕圖示即可開啟選單。SteamVR 儀表板開啟時，選單可能會隱藏。若選單未顯示，請參閱[常見問題](../troubleshooting/common-issues)。
