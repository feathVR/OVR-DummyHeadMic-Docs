# 確認控制器按鍵綁定

VR 按鈕名稱會依 SteamVR 控制器按鍵綁定而異。本應用程式的**使用方式**頁面會顯示在步驟 3（放置假人頭）與步驟 5（切換空間音訊）中可讀取到的按鍵綁定名稱。請先確認該處顯示的內容。

常見 Quest 類型控制器的按鍵綁定如下：

| 動作 | 常見按鈕 |
| --- | --- |
| 讓假人頭跟隨右手以進行放置 | 按住左手 X + 右手 A，或同時按住兩個 A 按鈕 |
| 切換空間音訊 | 按下左手 Y + 右手 B，或同時按下兩個 B 按鈕 |

其他控制器可能使用不同的按鈕名稱。若應用程式中的顯示與您的控制器不符，請在 SteamVR 中確認本應用程式的控制器按鍵綁定。當應用程式無法讀取按鍵綁定名稱時，可能會保留預設的範例文字。

請在**主要設定**中開啟或關閉手腕選單，並選擇要顯示在哪一隻手上。使用手腕圖示即可開啟選單。SteamVR 儀表板開啟時，選單可能會隱藏。若選單未顯示，請參閱[常見問題](../troubleshooting/common-issues)。
