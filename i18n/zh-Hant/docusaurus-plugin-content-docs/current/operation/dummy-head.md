# 放置假人頭

## 抓住並移動

使用控制器的握把抓住假人頭來移動。左右手皆可抓取。放開後，它會固定在該位置。

- **在近處抓取**：將手靠近頭部，頭部出現淺藍色輪廓線後握住握把。可以像拿在手中的物品一樣自由旋轉。
- **指向抓取**：用光束指向頭部並握住握把。移動時會保持所設的朝向；將搖桿往上推可移遠，往下推可移近，往左右推可橫向移動。

請確認適用於您控制器的[應用程式內按鍵綁定名稱](controllers)。

## 固定位置

用光束指向頭部時會出現按鈕列，按下其中的**固定位置**後，即使嘗試抓取，假人頭也不會移動。可避免定好位置後不小心移動它。再按一次**固定位置**即可解除。

## 朝向

可透過按鈕列中的**反轉朝向**，或**Main settings**中的「以右手放置時的臉部朝向」變更。

- **正面**：假人頭面向您（預設）。
- **背面**：假人頭與您面向相同方向。

以光束指向抓取並移動時，也會保持此朝向。

## 不透明度

按下按鈕列中的**透明度**，會依 100→60→30→10% 分四段切換。在**Main settings**的「仿真人頭透明度」中可以細部調整，也可以設為完全透明。若完全透明，可能會難以找到，因此建議在定位時讓它保持稍微可見。
