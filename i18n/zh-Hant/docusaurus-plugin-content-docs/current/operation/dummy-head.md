# 放置假人頭

## 手動移動

使用常見按鍵綁定時，按住左手 X + 右手 A，或同時按住兩個 A 按鈕，假人頭就會跟隨您的右手。將它移到所需位置後放開按鈕。請確認適用於您控制器的[應用程式內按鍵綁定名稱](controllers)。

<DummyHeadFigure part="place" />

## 朝向

請在**主要設定**的「連接至右手時的面部朝向」中變更此設定。

- **正面**：假人頭面向您。
- **背面**：假人頭與您面向相同方向。

<DummyHeadFigure part="facing" />

## 不透明度

使用「假人頭不透明度」調整顯示強度。若完全透明，可能會難以找到，因此建議在定位時讓它保持稍微可見。
