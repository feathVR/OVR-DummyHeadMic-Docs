# 主要設定參考

從應用程式左側導覽列開啟設定頁面。請先選擇[音訊路徑](../audio/routes)，再只調整您需要的設定。

## 主要設定

| 設定 | 變更內容 |
| --- | --- |
| ASMR | 開啟或關閉空間音訊。白色代表開啟；紅色代表關閉。 |
| 假人頭類型 | 變更聆聽設定檔：Standard、KU100 或 KEMAR。請戴上耳機比較。 |
| 空間設定 | 選擇房間殘響預設。「無殘響」可讓定位更容易確認。 |
| 輸出音量 | 設定處理後的音訊音量。也請確認 OBS 或 DAW 音量表。 |
| 假人頭不透明度 | 變更在 VR 中的可見度。完全透明可能會難以找到。 |
| 放置時的面部朝向 | 「正面」會面向您；「背面」會與您面向相同方向。 |
| 手臂選單 | 開啟／關閉手腕圖示，並選擇顯示在哪一隻手上。 |
| 與 VRChat 攝影機同步 | 開始或停止跟隨攝影機。請先進行[校正](../vrchat-camera/calibration)。 |
| 隨 SteamVR 自動啟動 | 開啟後，應用程式會從下次起與 SteamVR 一同啟動。這與 SteamVR 的**啟動／關閉 → 選擇啟動覆蓋應用程式**是同一項設定，因此兩處會顯示相同狀態。 |

## 使用方式

顯示標準流程與 VRChat 流程的步驟。每組步驟下方的按鈕會開啟教學影片及本手冊的對應頁面（標準使用方式為[播放第一個聲音](../getting-started/first-sound)，VRChat 則為 [VRChat 攝影機同步](../vrchat-camera/overview)）。應用程式使用英文時，會開啟英文手冊。

## 語言

使用設定視窗中的 **語言** 選擇顯示語言，共支援 8 種：日本語、English、简体中文、繁體中文、한국어、Русский、Español、Português (Brasil)。整個介面會立即切換，無需重新啟動；「使用方式」下方的手冊按鈕會開啟所選語言的手冊。初次啟動時，如果 Windows 的顯示語言屬於這 8 種之一，且電腦上有對應字型，應用程式會使用該語言，否則使用英文。側邊選單中的頁面名稱（如 Main settings）在所有語言下都維持英文。

## 音訊裝置設定

**音訊路徑**可選擇「一般」或 VST bridge。「一般」會使用麥克風與輸出裝置選項，並提供音訊中斷保護。VST bridge 會使用 DAW 的音訊設定。兩種路徑都可使用雜音抑制。請參閱[選擇音訊路徑](../audio/routes)。

## VRChat 攝影機位置與方向

- **攝影機前向偏移**：沿攝影機面向方向將聲學假人頭移動 0–100 cm。只有在需要讓聲音與影像對齊時才調整。
- **攝影機高度偏移**：將聲學位置垂直移動 −20 至 +20 cm。
- **聲學攝影機方向**：直向拍攝時選擇「直向」。此設定與 VRChat 的攝影機方向切換分開。

若位置偏差很大，請先確認 Local Anchor、校正以及攝影機的前／後切換，再調整偏移值。
