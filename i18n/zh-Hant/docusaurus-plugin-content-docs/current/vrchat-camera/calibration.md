# 校正攝影機

校正會測量 VRChat 中攝影機與實體控制器位置之間的關係。

1. 顯示 VRChat 攝影機，並在**與 VRChat 攝影機同步**下按下**開始**。
2. 等待「準備中」指示消失。
3. 用一隻手握住攝影機中央附近，保持水平並使用自拍方向。
4. 出現左右延伸的長條與圓點時，請保持高度與方向不變。沿著圓點的路徑緩慢向左右各移動一次，然後回到中央。
5. 在中央固定位置，使用手腕、前臂和手肘，平順地只變更攝影機的方向。
6. 綠色圓圈開始繪製時，請停止移動，並用同一隻手握住攝影機保持不動。
7. 出現「校正完成」後，將攝影機移至拍攝位置並放置。

![VRChat 攝影機同步的初始設定](/img/screenshots/zh-Hant/vrchat-camera-sync.png)

:::warning 校正期間的重要事項
- 校正完成前請勿換手。
- 握住攝影機時，請勿使用搖桿移動或轉向。
- 顯示「移動中」或「等待穩定」時，請勿抓取攝影機；只有在出現「就緒」後才繼續。
- 若提示返回左右移動步驟，請從長條步驟重新操作。
:::

## 直向錄影

僅在 VRChat 中將攝影機切換為直向，不會改變音訊方向。也請將**聲學攝影機方向**設為「直向」。

若提示不清楚或校正停止進行，請參閱[狀態指南](status)。
