# 瞭解攝影機同步狀態

校正期間請依照畫面上與 VR 內的提示操作。主要狀態如下：

| 顯示 | 意義與操作 |
| --- | --- |
| 在 VRChat 中開啟攝影機 | 顯示 User Camera，並確認 VRChat 中已啟用 OSC。 |
| MOVE | 應用程式偵測到移動。請勿抓取攝影機；停止移動或轉向。 |
| WAIT | 不要進行輸入，讓姿勢穩定下來。 |
| READY | 您可以抓取攝影機並繼續[校正步驟](calibration)。 |
| 跟隨圓點左右移動 | 保持攝影機高度與方向不變；沿直線緩慢移動。 |
| 綠色圓圈 | 用同一隻手將攝影機保持在中央不動，直到確認完成。 |
| 跟隨中 | 攝影機跟隨已啟用。 |
| 已暫停：超出範圍 | 回到虛擬人偶周圍約 2.5 m 內以恢復同步。 |
| 已暫停：請移動一次攝影機 | 稍微移動攝影機，讓 VRChat 傳送新的姿勢資料。 |
| 位置遺失：正在重新開始校正 | 再次從頭依照校正提示操作。 |

若 MOVE 或 WAIT 長時間持續顯示，請確認握住攝影機時沒有使用搖桿移動或轉向。如需瞭解 OSCQuery 備用連接埠訊息，請參閱[常見問題](../troubleshooting/common-issues)。
