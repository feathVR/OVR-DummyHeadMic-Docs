# VRChat 攝影機同步

此功能可讓假人頭麥克風自動跟隨 VRChat User Camera 的位置。它能減少「影像來自 VRChat 攝影機，但音訊卻來自其他位置」的不一致情況。

## 開始之前

1. 開啟 VRChat Action Menu。
2. 開啟**選項 → OSC**。
3. 啟用 OSC。
4. 顯示 VRChat User Camera。
5. 在 OVR-DummyHeadMic 中開啟**主要設定**。

通常會自動偵測連線。在可使用 OSCQuery 的環境中，您可以同時使用其他支援 OSC 的應用程式。

接著請[校正攝影機](calibration)。

開始同步後若出現 MOVE、WAIT 和 READY 等訊息，請參閱[狀態指南](status)。
