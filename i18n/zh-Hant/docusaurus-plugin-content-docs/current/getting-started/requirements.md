# 系統需求

使用前請準備以下項目：

- Windows 10 或 Windows 11 電腦
- Steam 與 SteamVR
- SteamVR 可辨識的 HMD，以及左右控制器
- 麥克風
- 耳罩式耳機或入耳式耳機
- 若要直播或錄影，需準備 OBS Studio 或其他擷取軟體
- 若要使用 VRChat 攝影機同步，需準備 PC 版 VRChat

:::warning 請使用耳機
若要確認雙耳音訊的定位，必須使用耳罩式耳機或入耳式耳機。透過喇叭播放麥克風音訊也可能造成回授。
:::

## 選擇音訊輸出

直播時，若使用本應用程式專用的虛擬音訊裝置或未使用的輸出裝置，音訊會更容易管理。若使用與日常喇叭相同的輸出，OBS 也可能擷取到遊戲音訊和通知音效。
