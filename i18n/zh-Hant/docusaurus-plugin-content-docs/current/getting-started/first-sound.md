# 播放第一個聲音

第一次確認時，請手動放置假人頭，不使用 VRChat 攝影機同步來確認聲音。

1. 啟動 SteamVR。
2. 啟動 OVR-DummyHeadMic。它會在不顯示視窗的情況下啟動，並常駐於 Windows 系統匣（畫面右下角的通知區域）。按一下系統匣圖示即可開啟設定視窗。
3. 在**音訊裝置設定**中選擇「一般」音訊路徑，並選擇[輸入與輸出裝置](../audio/devices)。
4. 戴上耳機，對著麥克風說話，確認能聽見音訊。
5. 確認您的[控制器按鍵綁定](../operation/controllers)。常見按鍵綁定為左手 X + 右手 A，或同時按住兩個 A 按鈕；按住這些按鈕，同時用右手移動假人頭。
6. 移到假人頭任一側，確認聽起來的語音位置會改變。
7. 若要直播或錄影，請設定 [OBS 音訊擷取](../audio/obs)。

![OVR-DummyHeadMic 的基本設定與操作](/img/screenshots/en/basic-guide.png)

_輸入與輸出、OBS 擷取、移動位置及切換空間音訊的概覽。_

:::tip 如果難以分辨聲音位置
將假人頭放在您的前方，接著在距離不遠處大幅向左右移動。初次確認時，請將空間殘響設為「無殘響」，以便更容易判斷直達聲的位置。
:::
