# 输入和输出设备

在 **音频设备设置** 的 Normal 音频路由中，选择接收你声音的输入设备，以及传输处理后音频的输出设备。如需使用 DAW，请按照 [VST 桥接](vst-bridge)说明操作。

## 输入设备

选择用于直播或录音的麦克风或音频接口。“Default Device”使用 Windows 默认输入设备。

## 输出设备

如果仅用于监听，请选择耳机所连接的输出设备。若使用 OBS，建议选择专供本应用使用的输出设备，例如虚拟音频设备。

更改输出设备会重启音频引擎。请稍等片刻，声音恢复后再进行检查。

如果下次启动时找不到已保存的设备，应用会回退到 Default Device。拔出设备或更改设备名称后，请检查所选设备。

:::warning
通过扬声器直接播放麦克风音频可能会引起反馈啸叫。配置应用时请使用头戴式耳机或入耳式耳机。
:::
