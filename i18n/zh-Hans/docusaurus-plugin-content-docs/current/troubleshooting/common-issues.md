# 常见问题

## 启动应用后没有出现窗口

OVR-DummyHeadMic 启动时不会显示窗口，而是驻留在 Windows 系统托盘（屏幕右下角的通知区域）中。

- 点击 OVR-DummyHeadMic 托盘图标打开设置窗口。如果看不到图标，请打开通知区域中的“^”。
- 右键点击图标可选择 **打开设置** 或 **退出 OVR-DummyHeadMic**。
- 窗口的关闭按钮（×）不会退出应用；它会让应用返回托盘。如需退出，请使用托盘菜单。
- 如果希望启动时显示窗口而不是进入托盘，请添加 `-showwindow` 启动选项。

## 没有声音

- 检查 **音频路由** 是 Normal 还是 VST bridge。如果不使用 DAW，请选择 Normal。
- 检查输入设备是否为正在使用的麦克风。
- 检查输出设备是否与耳机的连接位置相符。
- 检查 Windows 和应用中的静音及音量设置。
- 检查是否有其他应用以独占方式使用音频设备。
- 更改设备后，请稍等片刻，让音频引擎重新启动。

## 音频未到达 OBS

- 以下步骤适用于 Normal 路由。使用 VST bridge 时，请检查 [DAW 路由](../audio/vst-bridge)。
- 在 OBS 中添加 **音频输出采集**，而不是“音频输入采集”。
- 在 OVR-DummyHeadMic 和 OBS 中选择同一个输出设备。
- 检查 OBS 来源和音频混音器是否已静音。

## 同时听到未处理和已处理的声音

将 OBS 中常规的麦克风输入静音。直播时，只使用采集 OVR-DummyHeadMic 输出的音频输出采集。

## 无法移动假人头

- 检查 SteamVR 是否识别到两个控制器。
- 同时按住左手 X + 右手 A，或两侧的 A 按钮。
- 如果 VRChat 摄像机同步处于活动状态，请暂时结束同步，以恢复手动放置。
- 对于其他控制器或自定义绑定，请检查[应用内绑定名称](../operation/controllers)。

## 音频丢失或出现多余噪声

- 在 Normal 模式下，尝试音频设备设置中的 **防止音频丢失（环形缓冲区）**。切换该设置会重启音频引擎。
- 对于稳定的背景噪声，请尝试降噪。如果它改变了声音的特性，请将其关闭。
- 检查设备连接，以及是否有其他应用以独占方式使用设备。

## VST 桥接无法连接

- 在 DAW 中插入 `VOrbit Bridge`，必要时重新扫描插件。
- 将 DAW 采样率设置为 44.1 或 48 kHz。
- 如果其他应用正在使用该桥接，请先结束其中的桥接模式。
- 有关具体消息，请参阅 [VST 桥接状态指南](../audio/vst-bridge)。

## 未检测到 VRChat 摄像机

- 检查 VRChat Action Menu 中是否启用了 OSC。
- 按“开始”前先显示 User Camera。
- 如果重新启动了 VRChat 或本应用，请再次按“开始”。
- 检查防火墙或安全软件是否阻止本地通信、mDNS 或 OSC。
- 如果消息提示 OSCQuery 无法启动，请检查是否与其他 OSC 接收应用存在端口冲突。

## 校准无法完成

- 保持摄像机水平，并用同一只手缓慢移动。
- 左右移动时，保持朝向和高度稳定，向每个方向各直线移动一次。
- 测量朝向时，保持位置固定，只改变摄像机朝向。
- 手持摄像机时不要使用摇杆移动或转身。

## 同步位置有偏移

- 检查摄像机的自拍/朝外朝向在校准后是否发生了变化。
- 更换或重新加载虚拟形象后请重新校准。
- 竖屏拍摄时，将“声学摄像机朝向”设置为“Portrait”。
- 使用 Local Anchor，不要使用 World Anchor 或 Pin。

如果问题仍然存在，请参阅[问题报告方法](report)。
