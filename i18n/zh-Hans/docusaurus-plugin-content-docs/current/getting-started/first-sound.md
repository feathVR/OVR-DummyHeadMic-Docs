# 播放第一个声音

首次检查时，请手动放置假人头，不使用 VRChat 摄像机同步来确认声音。

1. 启动 SteamVR。
2. 启动 OVR-DummyHeadMic。它启动时不会显示窗口，而是驻留在 Windows 系统托盘（屏幕右下角的通知区域）中。点击托盘图标打开设置窗口。
3. 在 **音频设备设置** 中，选择 Normal 音频路由并选择[输入和输出设备](../audio/devices)。
4. 戴上耳机，对着麦克风说话，确认能够听见音频。
5. 检查你的[控制器绑定](../operation/controllers)。典型绑定为左手 X + 右手 A，或两侧的 A 按钮；按住这些按钮，同时用右手移动假人头。
6. 移动到假人头任意一侧，确认听起来的声源位置会发生变化。
7. 如果要直播或录音，请配置 [OBS 音频采集](../audio/obs)。

:::tip 如果难以分辨声音位置
将假人头放在你面前，然后在稍远处大幅向左右两侧移动。初次检查时，请将房间混响设置为“No reverb”，这样更容易判断直达声的位置。
:::
