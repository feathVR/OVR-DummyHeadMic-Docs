# 系统要求

使用前请准备以下项目：

- Windows 10 或 Windows 11 电脑
- Steam 和 SteamVR
- SteamVR 能够识别的 HMD 以及左右手控制器
- 麦克风
- 头戴式耳机或入耳式耳机
- 如果计划直播或录音，需要 OBS Studio 或其他采集软件
- 如果计划使用 VRChat 摄像机同步，需要 PC 版 VRChat

:::warning 使用耳机
要检查双耳音频定位，必须使用头戴式耳机或入耳式耳机。通过扬声器播放麦克风音频也可能引起反馈啸叫。
:::

## 选择音频输出

直播时，如果使用专供本应用使用的虚拟音频设备或闲置输出设备，音频会更易于管理。如果使用日常扬声器所用的同一输出，游戏音频和通知声音也可能被 OBS 采集。
