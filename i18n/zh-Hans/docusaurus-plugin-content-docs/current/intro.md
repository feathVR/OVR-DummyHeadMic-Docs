# OVR-DummyHeadMic 用户指南

OVR-DummyHeadMic 是一款 Windows SteamVR 叠加层应用，可在 VR 中放置虚拟假人头麦克风，并将你的声音实时转换为双耳音频。它能让 VR 直播和录音反映说话者相对于麦克风的位置。

本指南说明如何配置音频设备、将音频路由至 OBS、放置假人头、调整空间音频、与 VRChat 摄像机同步，以及排查问题。
