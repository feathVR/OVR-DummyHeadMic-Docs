# 放置假人头

## 手动移动

使用典型绑定时，按住左手 X + 右手 A，或两侧的 A 按钮，假人头便会跟随你的右手。将其移到所需位置，然后松开按钮。请检查适用于你控制器的[应用内绑定名称](controllers)。

<DummyHeadFigure part="place" />

## 面部朝向

在 **主设置** 的“附着于右手时的面部朝向”中更改此项。

- **Front**：假人头面向你。
- **Back**：假人头与你朝向相同的方向。

<DummyHeadFigure part="facing" />

## 不透明度

使用“假人头不透明度”调整显示强度。如果完全透明，可能会难以找到，因此建议定位时让它保持轻微可见。
