# 放置假人头

## 抓住并移动

用控制器的握把抓住假人头来移动它。左右手都可以抓取。松手后，它会固定在该位置。

- **在近处抓取**：把手靠近头部，头部出现浅蓝色轮廓线后握住握把。可以像拿在手里的物体一样自由旋转。
- **指向抓取**：用光束指向头部并握住握把。它会保持所设的面部朝向移动；摇杆向上推可移远，向下推可移近，向左右推可横向移动。

请检查适用于你控制器的[应用内绑定名称](controllers)。

## 固定位置

用光束指向头部时会出现按钮栏，按下其中的**固定位置**后，即使尝试抓取，假人头也不会移动。可防止定好位置后不小心移动它。再按一次**固定位置**即可解除。

## 面部朝向

可通过按钮栏中的**反转朝向**，或 **Main settings** 中的“右手放置时的面部朝向”更改。

- **Front**：假人头面向你（默认）。
- **Back**：假人头与你朝向相同的方向。

用光束指向抓取并移动时，也会保持此朝向。

## 不透明度

按下按钮栏中的**透明度**，会按 100→60→30→10% 四档切换。在 **Main settings** 的“仿真人头透明度”中可以细致调整，也可以设为完全透明。如果完全透明，可能会难以找到，因此建议定位时让它保持轻微可见。
