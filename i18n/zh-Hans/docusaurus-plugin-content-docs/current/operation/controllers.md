# 检查控制器绑定

VR 按钮名称取决于你的 SteamVR 控制器绑定。本应用的 **使用方法** 页面会显示它能读取到的第 3 步（放置假人头）和第 5 步（切换空间音频）的绑定名称。请先检查该显示。

典型的 Quest 风格控制器绑定为：

| 操作 | 典型按钮 |
| --- | --- |
| 让假人头跟随右手进行放置 | 按住左手 X + 右手 A，或两侧的 A 按钮 |
| 切换空间音频 | 按左手 Y + 右手 B，或两侧的 B 按钮 |

其他控制器可能使用不同的按钮名称。如果应用显示与控制器不符，请在 SteamVR 中检查本应用的控制器绑定。当应用无法读取绑定名称时，可能会保留默认示例文本。

在 **主设置** 中开启或关闭手腕菜单，并选择显示菜单的手。使用手腕图标将其打开。SteamVR 仪表板打开时，菜单可能会被隐藏。如果菜单未出现，请参阅[常见问题](../troubleshooting/common-issues)。
