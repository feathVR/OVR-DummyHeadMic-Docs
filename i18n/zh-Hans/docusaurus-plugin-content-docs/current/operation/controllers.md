# 检查控制器绑定

VR 按钮名称取决于你的 SteamVR 控制器绑定。本应用的 **使用方法** 页面会在第 3 步（抓取假人头）中显示它能读取到的绑定名称。请先检查该显示。

典型操作如下。左右手的用法相同。

| 操作 | 方法 |
| --- | --- |
| 在近处抓住并移动 | 把手靠近头部，出现浅蓝色轮廓线后握住握把 |
| 从远处抓住并移动 | 用光束指向头部，然后握住握把 |
| 使用按钮栏 | 用光束指向头部，头部下方会出现按钮栏；指向按钮并扣下扳机 |

按钮栏从左到右依次为：

| 按钮 | 作用 |
| --- | --- |
| 空间音频（ASMR） | 开启或关闭空间音频处理 |
| 空间设置 | 选择房间的混响（[房间预设](sound)） |
| 透明度 | 按 100→60→30→10% 的顺序切换显示浓度 |
| 固定位置 | 让假人头无法被抓取，防止误移 |
| 反转朝向 | 在 Front 与 Back 之间切换[面部朝向](dummy-head) |

其他控制器可能使用不同的按钮名称。如果应用显示与控制器不符，请在 SteamVR 中检查本应用的控制器绑定。当应用无法读取绑定名称时，可能会保留默认示例文本。

在 **主设置** 中开启或关闭手腕菜单，并选择显示菜单的手。使用手腕图标将其打开。SteamVR 仪表板打开时，菜单可能会被隐藏。如果菜单未出现，请参阅[常见问题](../troubleshooting/common-issues)。
