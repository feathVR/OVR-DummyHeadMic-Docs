# VRChat 摄像机同步

此功能可让假人头麦克风自动跟随 VRChat User Camera 的位置。它可以减少“画面来自 VRChat 摄像机，但声音却来自其他位置”这种不一致。

## 开始之前

1. 打开 VRChat Action Menu。
2. 打开 **Options → OSC**。
3. 启用 OSC。
4. 显示 VRChat User Camera。
5. 打开 OVR-DummyHeadMic 中的 **主设置**。

连接通常会被自动检测。在 OSCQuery 可用的环境中，可以同时使用其他支持 OSC 的应用。

接下来，请[校准摄像机](calibration)。

开始同步后，如果出现 MOVE、WAIT 和 READY 等消息，请参阅[状态指南](status)。
