# 校准摄像机

校准会测量 VRChat 中的摄像机与实体控制器位置之间的关系。

1. 显示 VRChat 摄像机，然后在 **与 VRChat 摄像机同步** 下按 **开始**。
2. 等待“准备中”指示消失。
3. 用一只手握住摄像机中央附近，使其保持水平并处于自拍朝向。
4. 出现较长的左右横条和圆点时，保持高度和朝向稳定。沿圆点路径缓慢左右各移动一次，然后回到中央。
5. 在中央保持位置固定，仅使用手腕、前臂和手肘平稳地改变摄像机朝向。
6. 绿色圆圈开始绘制时，停止移动，并继续用同一只手握住摄像机保持静止。
7. 出现“校准完成”后，将摄像机移动到拍摄位置并放在那里。

![VRChat 摄像机同步的初始设置](/img/screenshots/en/vrchat-camera-sync.png)

:::warning 校准期间的重要注意事项
- 校准完成前不要换手。
- 手持摄像机时不要使用摇杆移动或转身。
- 显示“移动中”或“等待稳定”时不要抓取摄像机；仅在出现“准备就绪”后继续。
- 如果提示返回左右移动步骤，请从长横条步骤开始重复操作。
:::

## 竖屏录制

仅在 VRChat 中将摄像机改为竖屏朝向，并不会改变音频朝向。还需将 **声学摄像机朝向** 设置为“Portrait”。

如果提示不清楚或校准停止推进，请参阅[状态指南](status)。
