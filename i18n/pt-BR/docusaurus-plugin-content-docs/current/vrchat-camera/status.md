# Entender o status da sincronização da câmera

Durante a calibração, siga as instruções exibidas na tela e em VR. Estes são os estados principais:

| Exibição | Significado e ação |
| --- | --- |
| Abra a câmera no VRChat | Exiba a User Camera e verifique se o OSC está ativado no VRChat. |
| MOVE | O aplicativo detecta movimento. Não pegue a câmera; pare de se mover ou girar. |
| WAIT | Deixe a pose se estabilizar sem fazer movimentos. |
| READY | Você pode pegar a câmera e continuar as [etapas da calibração](calibration). |
| Siga o ponto para a esquerda e para a direita | Mantenha a altura e a orientação da câmera estáveis; mova-a lentamente em linha reta. |
| Círculo verde | Mantenha a câmera imóvel no centro com a mesma mão até a confirmação ser concluída. |
| Acompanhando | O acompanhamento da câmera está ativo. |
| Pausado: fora de alcance | Volte para uma distância de cerca de 2.5 m do seu avatar para retomar. |
| Pausado: mova a câmera uma vez | Mova a câmera levemente para que o VRChat envie uma nova pose. |
| Posição perdida: reiniciando a calibração | Siga novamente as instruções de calibração desde o início. |

Se MOVE ou WAIT permanecer por muito tempo, verifique se você não está se movendo ou girando com o analógico enquanto segura a câmera. Para uma mensagem sobre a porta alternativa do OSCQuery, consulte [problemas comuns](../troubleshooting/common-issues).
