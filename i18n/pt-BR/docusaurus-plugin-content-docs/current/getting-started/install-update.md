# Instalar e atualizar

Obtenha o OVR-DummyHeadMic em sua fonte de distribuição. A instalação depende da edição recebida.

## Edição distribuída manualmente

1. Extraia o arquivo fornecido.
2. Mantenha todos os itens da pasta extraída juntos. Não mova separadamente arquivos incluídos, como `OVR-DummyHeadMic_Data`.
3. Inicie o SteamVR e depois o `OVR-DummyHeadMic.exe`; em seguida, siga [Reproduzir seu primeiro som](first-sound).

:::tip
Para iniciar o aplicativo com o SteamVR todas as vezes, ative **Iniciar automaticamente com o SteamVR** em **Configurações principais** (consulte a [referência das Configurações principais](../operation/settings)). Se você mover a pasta, inicie uma vez o `OVR-DummyHeadMic.exe` no novo local.
:::

Para atualizar, obtenha um novo pacote completo na fonte de distribuição. Extrair o pacote completo em uma nova pasta evita misturar arquivos incluídos antigos e novos. As configurações são salvas no aplicativo, mas verifique a rota de áudio, os dispositivos e a sincronização com o VRChat após a atualização.

Se você usa a ponte VST, também [copie novamente o `VOrbit Bridge.vst3` recém-incluído](../audio/vst-bridge) para o diretório de varredura da DAW.

## Edição Steam

Use o processo de instalação e atualização do Steam para a edição Steam. Consulte a fonte de distribuição para ver anúncios de lançamentos e diferenças em relação à edição distribuída manualmente.
