# Requisitos

Prepare o seguinte antes de usar:

- Um PC com Windows 10 ou Windows 11
- Steam e SteamVR
- Um HMD e controles esquerdo e direito reconhecidos pelo SteamVR
- Um microfone
- Fones de ouvido
- OBS Studio ou outro software de captura, se você pretende transmitir ou gravar
- A versão para PC do VRChat, se você pretende usar a sincronização da câmera do VRChat

:::warning Use fones de ouvido
É necessário usar fones de ouvido para verificar o posicionamento do áudio binaural. Reproduzir o áudio do microfone pelos alto-falantes também pode causar microfonia.
:::

## Escolher uma saída de áudio

Para transmissões, é mais fácil gerenciar o áudio se você usar um dispositivo de áudio virtual dedicado a este aplicativo ou um dispositivo de saída que não esteja em uso. Se você usar a mesma saída dos alto-falantes do dia a dia, o áudio do jogo e os sons de notificação também poderão ser capturados pelo OBS.
