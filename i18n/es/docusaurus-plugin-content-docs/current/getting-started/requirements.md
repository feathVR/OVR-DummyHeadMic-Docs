# Requisitos

Prepara lo siguiente antes de usar la aplicación:

- Una PC con Windows 10 o Windows 11
- Steam y SteamVR
- Un HMD y controles izquierdo y derecho reconocidos por SteamVR
- Un micrófono
- Audífonos
- OBS Studio u otro software de captura si planeas transmitir o grabar
- La versión para PC de VRChat si planeas usar la sincronización con la cámara de VRChat

:::warning Usa audífonos
Se requieren audífonos para comprobar la posición del audio binaural. Reproducir el audio del micrófono por altavoces también puede causar retroalimentación.
:::

## Elegir una salida de audio

Para transmitir, es más fácil administrar el audio si usas un dispositivo de audio virtual dedicado a esta aplicación o un dispositivo de salida que no utilices. Si usas la misma salida que tus altavoces habituales, OBS también puede capturar el audio del juego y los sonidos de notificación.
