# Guía del usuario de OVR-DummyHeadMic

OVR-DummyHeadMic es una aplicación superpuesta de SteamVR para Windows que coloca un micrófono de cabeza binaural virtual en VR y convierte tu voz en audio binaural en tiempo real. Permite que las transmisiones y grabaciones de VR reflejen la posición del hablante con respecto al micrófono.

Esta guía explica cómo configurar dispositivos de audio, enrutar el audio a OBS, colocar la cabeza binaural, ajustar el audio espacial, sincronizarla con la cámara de VRChat y solucionar problemas.
