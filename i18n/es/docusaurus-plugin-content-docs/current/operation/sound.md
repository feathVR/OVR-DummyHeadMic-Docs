# Configuración del audio espacial

![Pantalla actual de Configuración principal en inglés](/img/screenshots/en/app-window-en.png)

_La pantalla actual de Configuración principal en inglés, capturada desde la aplicación. Incluye el interruptor de audio espacial, el tipo de cabeza binaural, el preajuste de sala, el volumen de salida, la dirección de colocación y la configuración del menú del brazo._

## Activar o desactivar el audio espacial

Con las asignaciones habituales, presiona Y izquierdo + B derecho, o ambos botones B, para activar o desactivar el procesamiento de audio espacial. La cabeza binaural es blanca cuando está ACTIVADO y roja cuando está DESACTIVADO. Comprueba los [nombres de las asignaciones en la aplicación](controllers) para tu control.

## Tipo de cabeza binaural

- **Estándar**: para uso general, como conversaciones con varias personas
- **KU100**: un carácter de alta calidad adecuado para transmisiones individuales y ASMR
- **KEMAR**: un carácter basado en mediciones que incluyen el torso

La percepción varía de una persona a otra. Compáralos con audífonos y elige el que mejor se adapte a tu uso.

## Preajuste de sala

Elige entre “Sin reverberación”, sala pequeña, baño, salón, túnel y otros preajustes. Recomendamos “Sin reverberación” para las comprobaciones iniciales y el posicionamiento. Una reverberación intensa puede dificultar la evaluación de la dirección del sonido directo.

## Volumen de salida

Ajusta el volumen para evitar la saturación y comprueba también el nivel final de la transmisión en el medidor de OBS.
