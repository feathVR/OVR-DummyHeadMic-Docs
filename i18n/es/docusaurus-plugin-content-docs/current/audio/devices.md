# Dispositivos de entrada y salida

En la ruta de audio Normal, en **Configuración del dispositivo de audio**, selecciona el dispositivo de entrada que recibe tu voz y el dispositivo de salida que transporta el audio procesado. Si usas una DAW, sigue las instrucciones del [puente VST](vst-bridge).

## Dispositivo de entrada

Selecciona el micrófono o la interfaz de audio que usas para transmitir o grabar. “Dispositivo predeterminado” utiliza la entrada predeterminada de Windows.

## Dispositivo de salida

Si solo quieres monitorear, selecciona la salida a la que están conectados tus audífonos. Para OBS, recomendamos una salida dedicada a esta aplicación, como un dispositivo de audio virtual.

Al cambiar el dispositivo de salida, se reinicia el motor de audio. Espera unos instantes a que regrese el sonido antes de comprobarlo.

Si un dispositivo guardado no está disponible la próxima vez que inicies la aplicación, esta usará el Dispositivo predeterminado. Comprueba tu selección después de desconectar o cambiar el nombre de un dispositivo.

:::warning
Reproducir el audio del micrófono directamente por altavoces puede causar retroalimentación. Usa audífonos mientras configuras la aplicación.
:::
