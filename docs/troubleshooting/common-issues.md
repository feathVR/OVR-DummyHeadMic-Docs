# よくある問題

## 起動してもウィンドウが表示されない

OVR-DummyHeadMicは起動するとウィンドウを表示せず、Windowsのタスクトレイ（画面右下の通知領域）へ格納されます。

- トレイのOVR-DummyHeadMicアイコンをクリックすると、設定画面が開きます。アイコンが見当たらないときは、通知領域の「^」を開きます。
- アイコンを右クリックすると「設定を開く」「OVR-DummyHeadMic を終了」を選べます。
- 設定画面の閉じるボタン（×）はアプリを終了せず、再びトレイへ格納します。終了するときはトレイのメニューから終了します。
- トレイを使わずにウィンドウを表示したまま起動したいときは、起動オプションに`-showwindow`を付けます。

## 音が出ない

- **音声経路**が「通常」か「VSTブリッジ」かを確認します。DAWを使わない場合は「通常」を選びます。
- 入力デバイスが使用するマイクになっているか確認します。
- 出力デバイスとヘッドホンの接続先が一致しているか確認します。
- Windowsとアプリのミュート、音量を確認します。
- ほかのアプリがオーディオデバイスを排他的に使用していないか確認します。
- デバイス変更直後は、オーディオエンジンの再起動を少し待ちます。

## OBSへ音が入らない

- この手順は「通常」の音声経路用です。VSTブリッジは[DAW側の経路](../audio/vst-bridge)を確認します。
- OBSには「音声入力キャプチャ」ではなく**音声出力キャプチャ**を追加します。
- OVR-DummyHeadMicとOBSで同じ出力デバイスを選びます。
- OBSのソースと音声ミキサーがミュートされていないか確認します。

## 生の声と処理後の声が二重に聞こえる

OBS側の通常のマイク入力をミュートします。配信に使用するのは、OVR-DummyHeadMicの出力を取り込む音声出力キャプチャだけにします。

## ダミーヘッドを動かせない

- SteamVRで左右のコントローラーが認識されているか確認します。
- 左手X＋右手A、または両手Aを同時に押します。
- VRChatカメラ同期中は、いったん同期を終了して手動設置へ戻します。
- 別の機種やカスタムバインドでは[アプリ内のボタン表示](../operation/controllers)を確認します。

## 音が途切れる、ノイズが気になる

- 通常経路で音が途切れる場合は、**Audio device settings**の「音切れ対策（リングバッファ）」を試します。切り替え時に音声エンジンが再起動します。
- 定常的な環境ノイズにはノイズ除去を試せます。声の質感が変わる場合はOFFへ戻します。
- デバイスの接続状態と、ほかのアプリの排他使用も確認します。

## VSTブリッジが接続しない

- DAWに`VOrbit Bridge`を挿入し、プラグインを再スキャンしたか確認します。
- DAWのサンプルレートを44.1または48 kHzにします。
- 「別のアプリが使用中」と表示されたら、先に接続したアプリのブリッジ経路を終了します。
- 状態表示ごとの対処は[VSTブリッジの説明](../audio/vst-bridge)を参照してください。

## VRChatカメラを検出しない

- VRChatのAction MenuでOSCが有効か確認します。
- User Cameraを表示してから「開始」を押します。
- VRChatまたは本アプリを再起動した場合は、もう一度「開始」を押します。
- ファイアウォールやセキュリティソフトがローカル通信、mDNS、OSCを遮断していないか確認します。
- OSCQueryの開始に失敗した旨が表示された場合、ほかのOSC受信アプリとのポート競合を確認します。

## 較正が完了しない

- カメラを水平に保ち、同じ手でゆっくり操作します。
- 左右移動では向きと高さを変えず、直線的に1往復します。
- 向きの測定では位置を動かさず、カメラの向きだけを変えます。
- カメラを持ったままスティック移動や旋回をしないでください。

## 同期位置がずれた

- カメラの自撮り／外向きを較正時から変更していないか確認します。
- アバター変更・リロード後は再較正します。
- 縦撮影では「音響カメラ向き」を「縦向き」にします。
- World AnchorやPinではなくLocal Anchorを使用します。

解決しない場合は[問題の報告方法](report)を参照してください。
