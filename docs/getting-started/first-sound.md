# 最初の音を出す

最初はVRChatカメラ同期を使わず、手動でダミーヘッドを設置して音を確認します。

1. SteamVRを起動します。
2. OVR-DummyHeadMicを起動します。
3. **Audio device settings**で[入力・出力デバイス](../audio/devices)を選びます。
4. ヘッドホンを装着し、マイクへ話して音が聞こえることを確認します。
5. 左手X＋右手A、または両手のAボタンを押しながら、右手でダミーヘッドを移動します。
6. ダミーヘッドの左右へ移動し、声の位置が変化することを確認します。
7. 配信または録画をする場合は、[OBSへの取り込み](../audio/obs)を設定します。

![OVR-DummyHeadMicの基本的な設定と操作](/img/screenshots/ja/basic-guide.png)

_入力・出力、OBSへの取り込み、位置の移動、空間音声の切り替えの全体像です。_

:::tip 音の位置が分かりにくい場合
ダミーヘッドを正面に置き、少し離れた位置から左右へ大きく動いて確認してください。部屋の残響は一度「残響なし」にすると、直接音の位置を判断しやすくなります。
:::
