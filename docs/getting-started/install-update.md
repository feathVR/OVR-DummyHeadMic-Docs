# インストールと更新

OVR-DummyHeadMicは配布元から入手してください。配布方法によって導入手順が異なるため、入手した版の案内を確認します。

## 手動配布版

1. 配布されたアーカイブを展開します。
2. 展開したフォルダーを保ちます。`OVR-DummyHeadMic_Data`などの同梱ファイルを別の場所へ移さないでください。
3. SteamVRを起動してから`OVR-DummyHeadMic.exe`を起動し、[最初の音を出す](first-sound)へ進みます。

更新するときは、配布元の新しい一式を入手します。古いフォルダーにファイルを継ぎ足すより、新しいフォルダーへ一式を展開して起動する方が同梱物の混在を避けられます。設定はアプリ内に保存されますが、更新後は音声経路、デバイス、VRChat同期を確認してください。

VSTブリッジを使う場合は、更新後に同梱の`VOrbit Bridge.vst3`もDAWの検索先へ[コピーし直してください](../audio/vst-bridge)。

## Steam版

Steamで提供される版は、Steamの案内に従ってインストール・更新します。配布開始前の案内や、手動配布版とSteam版の違いは配布元の告知を確認してください。
