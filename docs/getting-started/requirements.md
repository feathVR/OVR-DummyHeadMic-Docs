# 必要な環境

使用前に次を用意します。

- Windows 10またはWindows 11のPC
- SteamおよびSteamVR
- SteamVRで認識されるHMDと左右のコントローラー
- 使用するマイク
- ヘッドホンまたはイヤホン
- 配信・録画に使用する場合はOBS Studioなどのキャプチャーソフト
- VRChatカメラ同期を使用する場合はVRChat PC版

:::warning ヘッドホンを使用してください
バイノーラル音響の定位確認にはヘッドホンまたはイヤホンが必要です。スピーカーでマイク音声を再生すると、ハウリングする可能性もあります。
:::

## 音声出力先について

配信では、本アプリ専用の仮想オーディオデバイスまたは未使用の出力デバイスを用意すると管理しやすくなります。普段使うスピーカーと同じ出力先にすると、ゲーム音や通知音もOBSへ入ることがあります。
