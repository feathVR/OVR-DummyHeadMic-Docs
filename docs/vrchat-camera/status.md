# カメラ同期の表示を読む

較正中は画面やVR内の案内に従って操作します。代表的な表示と対処は次のとおりです。

| 表示 | 意味・すること |
| --- | --- |
| VRChatでカメラを出してください | User Cameraを表示し、VRChatでOSCが有効か確認します。 |
| 移動中（MOVE） | アプリが移動を検出しています。カメラを掴まず、移動や旋回を止めます。 |
| 安定待ち（WAIT） | 姿勢が落ち着くのを待ちます。操作せずに待ちます。 |
| 準備OK（READY） | カメラを掴み、[較正手順](calibration)を進められます。 |
| 光点を追って左右へ | カメラの高さと向きを保ち、左右へゆっくり直線的に動かします。 |
| 緑の円 | 同じ手で持ったまま中央で静止し、確認完了を待ちます。 |
| 追従中 | カメラ位置への同期が有効です。 |
| 測定範囲外で待機 | アバターから約2.5 m以内に戻ると再開します。 |
| カメラを一度動かすと再開 | カメラを少し動かして新しい位置データを送ります。 |
| 位置がずれたため再較正 | 表示された較正案内を最初からやり直します。 |

「MOVE／WAIT」が長く続く場合は、カメラを保持したままスティック移動・旋回していないか確認します。OSCQueryの予備ポート表示が出る場合は、[よくある問題](../troubleshooting/common-issues)を参照してください。
