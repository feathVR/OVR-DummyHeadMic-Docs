# カメラを較正する

較正では、VRChat内のカメラと現実のコントローラーの位置関係を測定します。

1. VRChatカメラを表示し、「VRChatカメラと同期」の**開始**を押します。
2. 準備中の表示が消えるまで待ちます。
3. カメラ中央付近を片手で持ち、自撮りの向きで水平に構えます。
4. 長い左右バーと光点が出たら、高さと向きを保ったまま、光点に沿って左右へゆっくり1往復して中央へ戻します。
5. 中央で位置を動かさず、手首・前腕・肘を使ってカメラの向きだけを滑らかに変えます。
6. 緑の円が描かれ始めたら動きを止め、同じ手で持ったまま静止します。
7. 「較正完了」が表示されたら、カメラを撮影位置へ運んで置きます。

![VRChatカメラ同期の初回設定](/img/screenshots/ja/vrchat-camera-sync.png)

:::warning 較正中の重要事項
- 完了まで持つ手を替えないでください。
- カメラを持ったままスティック移動や旋回をしないでください。
- 「移動中」「安定待ち」の間はカメラを掴まず、「準備OK」になってから続けてください。
- 左右移動の案内へ戻った場合は、長いバーの手順からやり直してください。
:::

## 縦向きで撮影する

VRChat側でカメラを縦向きにしただけでは音響側の向きは変わりません。**音響カメラ向き**も「縦向き」に設定してください。
