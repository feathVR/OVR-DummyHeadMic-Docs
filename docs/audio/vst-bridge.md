# DAWでVSTブリッジを使う

VSTブリッジは、DAWの音声を`VOrbit Bridge.vst3`から本アプリへ送り、処理後の音をDAWへ返します。DAWを使わない場合は[通常経路](routes)を選んでください。

## 初回設定

1. 本アプリの**Audio device settings**で「VSTブリッジの場所を開く」を押します。
2. 表示された場所の`VOrbit Bridge.vst3`フォルダーを**丸ごと**DAWのVST3検索先へコピーします。ユーザー用は`%LOCALAPPDATA%\Programs\Common\VST3`、全ユーザー用は`%COMMONPROGRAMFILES%\VST3`です。DAWで独自の検索先を設定している場合はその場所を使います。
3. DAWのプラグイン一覧を再スキャンし、使用する音声トラックに**VOrbit Bridge**を挿入します。
4. DAWのサンプルレートを**44.1 kHzまたは48 kHz**に設定します。
5. 本アプリの「音声経路」を**VSTブリッジ**に切り替えます。状態が「空間化中」になり、DAWで音が聞こえることを確認します。

:::note
プラグインの表示名が「VOrbit Bridge」なのは同梱物の名称です。OVR-DummyHeadMic用に別名へ変更する必要はありません。
:::

## 状態表示と操作

| 表示 | 意味・次の操作 |
| --- | --- |
| DAWのVOrbit Bridgeを待機中 | DAWでプラグインを挿入し、音声処理を開始します。接続済みだった場合は「VSTブリッジに再接続」を試します。 |
| 空間化中 | 接続しています。DAWの入出力とトラックの音量を確認します。 |
| 非対応サンプルレート：素通し | DAWを44.1 kHzまたは48 kHzに変更します。 |
| オフライン書き出し中：素通し | オフライン書き出しでは空間化されません。リアルタイム再生で確認します。 |
| 別のアプリがVSTブリッジを使用中 | VOrbit ASMRなど、同じブリッジを使うアプリのブリッジ経路を終了してから再接続します。 |

「VSTブリッジを切断」は現在のDAW接続を解除します。DAW側のプラグインは素通し状態になります。「VSTブリッジに再接続」は待機中の接続を再試行します。

アプリを更新した後は、同梱フォルダーのプラグインもDAWの検索先へコピーし直し、DAWで再スキャンしてください。
