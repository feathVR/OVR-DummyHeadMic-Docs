# 入力・出力デバイス

**Audio device settings**で、声を受け取る入力デバイスと、処理後の音を送る出力デバイスを選びます。

## 入力デバイス

配信・収録に使用するマイクまたはオーディオインターフェースを選びます。「既定のデバイス」はWindowsの既定入力を使用します。

## 出力デバイス

確認だけなら、ヘッドホンを接続している出力先を選べます。OBSで使用する場合は、仮想オーディオデバイスなど本アプリ専用の出力先を推奨します。

出力先を変更すると、オーディオエンジンが再起動します。音が戻るまで少し待ってから確認してください。

:::warning
マイク音をスピーカーへ直接出すとハウリングする可能性があります。設定中もヘッドホンまたはイヤホンを使用してください。
:::
