# 音声経路を選ぶ

**Audio device settings → 音声経路**で、使い方に合わせて「通常」または「VSTブリッジ」を選びます。選択した経路は次回起動時にも復元されます。

| 経路 | 音の流れ | 主な用途 |
| --- | --- | --- |
| 通常 | マイク → OVR-DummyHeadMic → Windowsの出力デバイス | ヘッドホンでの確認、[OBSへの取り込み](obs) |
| VSTブリッジ | DAWのトラック → VOrbit Bridge.vst3 → OVR-DummyHeadMic → DAW | DAW内でのモニター・収録 |

最初は「通常」で音を確認してください。「VSTブリッジ」にすると入力・出力デバイスとリングバッファの設定欄が隠れ、音声デバイスはDAW側で設定します。通常経路用のOBS「音声出力キャプチャ」の手順は、VSTブリッジ経路にはそのまま当てはまりません。

## 共通設定

- **環境ノイズを控えめに軽減**：PCファンや空調など一定した音を弱めます。既定はOFFです。囁き声・息遣いの質感が変わる場合があり、アプリ側の遅延が約10 ms増えます。
- **音切れ対策（リングバッファ）**：通常経路で音切れするときに試します。切り替えると音声エンジンが再起動します。VSTブリッジ経路では表示されません。

遅延表示は内訳も示します。VSTブリッジでは、DAWや音声機器の入出力遅延はアプリ表示の数値に含まれません。
