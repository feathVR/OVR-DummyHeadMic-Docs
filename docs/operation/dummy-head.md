# ダミーヘッドの設置

## 掴んで動かす

ダミーヘッドは、コントローラーのグリップで掴んで動かします。左右どちらの手でも掴めます。手を離すと、その場所に固定されます。

- **近くで掴む**：手を頭に近づけ、頭に水色の輪郭線が出たらグリップを握ります。手に持った物と同じように、自由に回せます。
- **指して掴む**：ビームで頭を指してグリップを握ります。こちらを向いたまま動き、スティックの上で遠く、下で近く、左右で横へずらせます。

機種ごとの実際のボタン名は[アプリ内の使い方表示](controllers)で確認してください。

## ピン留め

ビームで頭を指すと出るボタン列の**ピン留め**を押すと、掴もうとしてもダミーヘッドが動かなくなります。位置を決めたあと、うっかり動かしてしまうのを防げます。外すときは、もう一度ピン留めを押します。

## 顔の向き

ボタン列の**向きの反転**か、**Main settings**の「右手で固定化される顔の向き」で変更します。

- **前方（Front）**：ダミーヘッドが自分と向き合う配置（既定）
- **後方（Back）**：ダミーヘッドが自分と同じ方向を向く配置

ビームで指して掴んで動かしているときも、この向きを保ちます。

## 透明度

ボタン列の**透明度**を押すと、100→60→30→10%の4段階で切り替わります。**Main settings**の「ダミーヘッドの透明度」では細かく調整でき、完全に透明にもできます。完全に透明にすると位置を見失いやすいため、設置中は少し表示を残すことを推奨します。
