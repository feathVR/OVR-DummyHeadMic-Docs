# コントローラーの操作を確認する

VRで使うボタンは、SteamVRのコントローラー割り当てに依存します。本アプリの**How to use（使い方）**は、取得できた実際の割り当て名を手順3（ダミーヘッドの設置）と手順5（空間音声の切り替え）に表示します。まずその表示を確認してください。

Quest系コントローラーでの代表例は次のとおりです。

| 操作 | 代表的なボタン |
| --- | --- |
| 右手に追従させて配置 | 左X＋右A、または両手Aを押し続ける |
| 空間音声のON/OFF | 左Y＋右B、または両手Bを同時に押す |

ほかのコントローラーではボタン名が異なります。アプリ内の表示が実際のコントローラーと合わない場合は、SteamVRの本アプリ用コントローラーバインドを確認してください。ボタン名を取得できないときは、アプリ内に代表例の文面が残る場合があります。

腕メニューは**Main settings**でON/OFFと表示する手を選択します。手首アイコンから操作でき、SteamVRダッシュボードを開いている間は表示が抑制される場合があります。表示されないときは[よくある問題](../troubleshooting/common-issues)も参照してください。
