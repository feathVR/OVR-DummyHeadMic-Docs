# コントローラーの操作を確認する

VRで使うボタンは、SteamVRのコントローラー割り当てに依存します。本アプリの**How to use（使い方）**は、取得できた実際の割り当て名を手順3（ダミーヘッドを掴む）に表示します。まずその表示を確認してください。

代表的な操作は次のとおりです。左右どちらの手でも同じように使えます。

| 操作 | やり方 |
| --- | --- |
| 近くで掴んで動かす | 手を頭に近づけ、水色の輪郭線が出たらグリップを握る |
| 離れたところから掴んで動かす | ビームで頭を指してグリップを握る |
| ボタン列を使う | ビームで頭を指すと頭の下にボタン列が出るので、ボタンを指してトリガーを引く |

ボタン列には、左から次のボタンが並びます。

| ボタン | 動作 |
| --- | --- |
| 空間音声（ASMR） | 空間音声処理のON/OFF |
| 空間設定 | 部屋の響き（[部屋プリセット](sound)）を選ぶ |
| 透明度 | 表示の濃さを100→60→30→10%の順に切り替える |
| ピン留め | ダミーヘッドを掴めなくして、うっかり動かすのを防ぐ |
| 向きの反転 | [顔の向き](dummy-head)を前方⇔後方で切り替える |

ほかのコントローラーではボタン名が異なります。アプリ内の表示が実際のコントローラーと合わない場合は、SteamVRの本アプリ用コントローラーバインドを確認してください。ボタン名を取得できないときは、アプリ内に代表例の文面が残る場合があります。

腕メニューは**Main settings**でON/OFFと表示する手を選択します。手首アイコンから操作でき、SteamVRダッシュボードを開いている間は表示が抑制される場合があります。表示されないときは[よくある問題](../troubleshooting/common-issues)も参照してください。
