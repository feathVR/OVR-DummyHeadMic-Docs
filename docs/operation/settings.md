# 主な設定項目

画面左側のメニューから各設定画面を開きます。まず[音声経路](../audio/routes)を決め、その後に必要な項目だけ変更してください。

## Main settings

| 項目 | 変更されるもの |
| --- | --- |
| ASMR | 空間音声処理のON/OFF。白がON、赤がOFFです。 |
| ダミーヘッドの種類 | 標準／KU100／KEMARの聞こえ方。ヘッドホンで比較します。 |
| 空間設定 | 残響の部屋プリセット。定位の確認時は「残響なし」が分かりやすいです。 |
| 出力音量 | 処理後の音量。OBSやDAW側でも音量メーターを確認します。 |
| ダミーヘッドの透明度 | VR内の表示濃度。完全に透明にすると見失いやすくなります。 |
| 右手で固定化される顔の向き | Frontは自分と向き合い、Backは自分と同じ方向を向きます。 |
| 腕メニュー | 手首アイコンのON/OFFと、表示する手の選択。 |
| VRChatカメラと同期 | カメラ追従の開始／終了。初回は[較正](../vrchat-camera/calibration)します。 |
| SteamVR起動時に自動で起動 | ONにすると、次からSteamVRの起動と同時に本アプリも起動します。SteamVRの設定「起動／シャットダウン → 起動時のオーバーレイアプリを選択」と同じ項目で、どちらで変えても一致します。 |

## How to use（使い方）

通常版とVRChat版の手順を表示します。各手順の下にあるボタンから、解説動画と、このマニュアルの該当ページ（通常版は[最初の音を出す](../getting-started/first-sound)、VRChat版は[VRChatカメラ同期](../vrchat-camera/overview)）を開けます。アプリを英語表示にしている場合は、マニュアルの英語版が開きます。

## Audio device settings

「音声経路」は通常とVSTブリッジを切り替えます。通常はマイクと出力デバイスを選び、音切れ対策を設定します。VSTブリッジではDAW側の音声設定を使用します。ノイズ除去は両経路に共通です。詳しくは[音声経路](../audio/routes)を参照してください。

## VRChatカメラ同期の位置・向き

- **カメラ前方オフセット**：カメラの向く方向に沿って、音響上のダミーヘッド位置を0～100 cm移します。映像と音の位置を合わせるため、必要なときだけ調整します。
- **カメラ上下オフセット**：音響位置を垂直方向へ−20～＋20 cm移します。
- **音響カメラ向き**：映像を縦撮影するときは「縦向き」を選びます。VRChat側の縦横切り替えとは別の設定です。

位置が大きくずれる場合はオフセットで補う前に、Local Anchor、較正状態、カメラの前後切り替えを確認してください。
