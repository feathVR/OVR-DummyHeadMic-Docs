# 空間音響の設定

## 空間音声の切り替え

代表的な割り当てでは、左手Y＋右手B、または両手Bを同時に押すと、空間音声処理のON/OFFを切り替えられます。ダミーヘッドが白いときはON、赤いときはOFFです。実際のボタン名は[アプリ内の使い方表示](controllers)で確認してください。

## ダミーヘッドの種類

- **標準**：複数人の会話など、広い用途向け
- **KU100**：ソロ配信やASMR向けの高音質な特性
- **KEMAR**：胴体を含む測定をもとにした特性

聞こえ方には個人差があります。ヘッドホンで比較し、用途に合うものを選んでください。

## 部屋プリセット

「残響なし」から小部屋、浴室、ホール、トンネルなどを選択できます。初回確認や位置調整では「残響なし」を推奨します。残響が強いと、直接音の方向が判断しにくくなる場合があります。

## 出力音量

音割れしない範囲に調整し、最終的な配信音量はOBSのメーターでも確認してください。
