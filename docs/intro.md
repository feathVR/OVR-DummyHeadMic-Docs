# OVR-DummyHeadMic 操作ガイド

OVR-DummyHeadMicは、VR空間に仮想のダミーヘッドマイクを置き、自分の声をリアルタイムでバイノーラル音響にするWindows向けSteamVRオーバーレイアプリです。VR配信や録画で、話し手とマイクの位置関係を音へ反映できます。

このガイドでは、音声デバイスの設定、OBSへの取り込み、ダミーヘッドの設置、空間音響の調整、VRChatカメラ同期、問題の切り分けを説明します。
